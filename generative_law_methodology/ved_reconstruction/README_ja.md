# VED reconstruction gate

> Status:
> - not started
> - no VED equation has been rewritten
> - this directory records only the application gate and audit schema

General-methodology stress tests must precede any VED application. Repository inspection identified the future targets but did not adjudicate them.

## Readiness gate

VED reconstruction may begin only after:

- definitional accessibility and independent target freedom have a tested separation;
- graph growth has been compared under fixed-state and changing-specification encodings;
- construction order and candidate emergent time/order are separated;
- metric construction controls cover metric, pseudometric, extended-distance, and failure cases;
- special terminology has either survived standard reductions or been retired.

## Required record per item

| Field | Required content |
|---|---|
| 1. Current equation | exact expression and source link |
| 2. Implicit structure | state space, topology, metric, time, differentiability, order, measure |
| 3. Ordinary role | law-like, update, definition, measurement, constitutive, constraint, approximation |
| 4. Generation claim | exact object / distinction / relation claimed to become available |
| 5. Logical form | existential, universal, necessity, sufficiency, uniqueness |
| 6. Sufficient evidence | evidence form required for that claim |
| 7. Current evidence | derivation, construction, simulation, analogy, conjecture, none |
| 8. Overclaim risk | prohibited inference |
| 9. Pregeometry / pretime audit | whether notation presupposes the target structure |
| 10. Rewrite candidate | only after evidence audit; may be “no rewrite” |

## Explicit circularity checks

- \(\nabla\) requires a graph differential or differential-geometric structure.
- \(\nabla\times\) requires dimension, orientation, and vector / differential-form structure.
- \(d/dt\) requires a parameter and differentiability.
- \(d(x,y)\) is already metric notation unless it is introduced by a proved construction from prior data.

These are questions about prerequisites, not prior verdicts that the VED formulas are invalid.
