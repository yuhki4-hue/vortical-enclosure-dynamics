# 登録事象のトポロジー署名:VED 次元創発における不可逆三角挿入の per-event β₁ 検証

**種別:** 検証記録(数値実施済み・再現性確認済み)。本文書の全数値主張は再現手順つきで記録される。
**上流依存:** VED core equation(`C_ij`, rank 1)、K1(登録の離散性=完了した区別、不可逆)、v24 成長モデル(`growth_v24.py`)、次元選択ワーキングノート §5.55–§5.60。
**計器:** `growth_v24_betti.py`(元コードに非破壊で per-event β₁ カウンタを差し込み)、`betti_repro.py`(再現性・収支集計版)。
**監査規律:** stochastic-quantization §0 を適用。測定された事実と、未証明の予想・解釈を各節で明示的に分離する。

---

## 0. この文書が確立すること・しないこと

**確立する(測定):** v24 モデルにおいて、計量窓を産出する転化則 T1 が「細分」ではなく **不可逆三角挿入** であり、一登録事象あたり例外なく β₁ を +1 する(極と cycle を同時に鋳造する)こと。cycle 生成が T1 の専売であり、通常登録(REG)・出芽(T2)・面貼り(T3_main)はいずれも cycle を生成しないこと。cycle の消尽(sink)が連続忘却と孤立死によって起こること。そして計量窓が β₁ の高い領域と対応すること。以上が N・seed をまたいで不変であること。

**確立しない:** (i) なぜ「間に入る」が次数 2 であって 1・0 でないかの公理からの一意性(これは紙上の予想のまま、§6 参照)。(ii) 収支↔窓が相関でなく因果であること(§5.4 は相関を示すが機構は未導出)。(iii) v24 モデル族を超えた一般性(転化則非依存性は §5.57.2 で既に否定されており、本検証は窓産出則 T1 の精密な性格づけであって則独立の主張ではない)。

---

## 1. 問いと、検証すべき命題

ワーキングノート §5.57 は「計量窓は細分(T1)でしか発生しない」を報告した。しかし `growth_v24.py` のコード読解により、実装 T1 は教科書的 subdivision(辺 i–j を消して i–a–j に置換)では **なく**、既存辺 i–j を保持したまま新極 a を i と j の両方へ接続する操作だと判明した:

```python
if TRULE == "T1":            # コメントは "subdivision" だが実体は違う
    a = free.pop(); alive[a] = True
    H[i, a] += 1.0; H[a, j] += 1.0   # H[i, j] は消さない → 三角 i–a–j–i を形成
```

これは一事象で **ΔV=+1, ΔE=+2, Δβ₁=+1**(極1つと独立サイクル1つの同時生成)を意味する。この読みが正しければ、以下が成り立つはずである。検証対象の五命題:

- **(P1)** T1 は常に (ΔV,ΔE,Δβ₁)=(+1,+2,+1)。
- **(P2)** T2(出芽)は常に (+1,+1,0)(極は作るが cycle を作らない=ペンダント)。
- **(P3)** REG(通常登録)は cycle を作らない(既存辺の強化のみ)。reflection・床発火の経路でも破れない。
- **(P4)** sink 側:連続忘却 `H*=(1-γ)` と孤立死が β₁ を減らす。
- **(P5)** T1 の source と sink の収支が、計量窓の有無と対応する。

**この検証の非自明性についての注記(過大主張の回避).** 各事象の Δ 値は、そのブランチが行う H 操作から**分岐ローカルには決まっている**(T1 が毎回二辺を足すのは自明)。検証の内容はそこではなく、(a) 新極 a が毎回真に次数 0 から始まり両辺が本当に新規か、(b) REG が reflection・床発火を含むあらゆる大域状態で一度も新辺を作らないか、(c) 台帳が閉じるか(捕捉漏れのトポロジー変化がゼロか)——という、コードを読むだけでは保証されない大域的性質である。分岐ローカルな意図が、rng 駆動の全経路・全大域状態で**漏れなく**成立することの確認が主眼。

---

## 2. 方法

**β₁ の定義.** 支持グラフ `{(i,j) : H[i,j]>1e-12 ∨ H[j,i]>1e-12}`(firing/outgoing の閾値に一致)を生存ノード上で構成し、β₁ = E − V + C(E=辺数、V=ノード数、C=連結成分数)。scipy の `connected_components` を使用。

**per-event 測定.** 各 H 変異(種生成・T1/T2/T3/REG の各分岐・連続忘却・孤立死)の直前直後で β₁ を測り、(ΔV,ΔE,Δβ₁) を分岐ラベルつきで集計。加算のみの事象では閾値を跨がない限り Δβ₁=0 が厳密に従うため、生成事象と新辺 REG のみ再計算(反証監視)。死・忘却は別台帳。

**非摂動の証明.** β₁ 測定は乱数を一切消費せず、事象順序も変えない。計器版と元コードの window 出力(status 行 + 全 window 行)が**バイト一致**することを確認済み(下記)。したがって測定は純粋観測であり、動力学を変えていない。

**台帳クロージャ監査.** 全 H 変異が捕捉されているなら、全事象の Δβ₁ の総和は最終 β₁ に等しいはずである(初期は空グラフ=β₁ 0)。これを毎 run で照合する。一致すれば「捕捉漏れゼロ」の証明になる。

**軸.** λ=0.9、γ=0.075、900 epochs 固定。転化則 T1 を N ∈ {300, 450, 650} × seeds {5,7,10,15,21,33}(計 18 seed-run)。対照として T2 を N=450 × 同 6 seeds。

---

## 3. 非摂動の確認

計器版 `growth_v24_betti.py` と元コード `growth_v24.py` を同一引数(g=0.075, 900ep, N=450, seeds 5/7/10, T1)で実行し、status 行と全 window 行が**完全一致**した。β₁ 計器は乱数ストリームにも事象順序にも触れていない。以降の全数値はこの純粋観測の上に立つ。

## 4. 結果:per-event 署名(P1–P3)

### 4.1 単一走の完全内訳(N=450, seeds 5/7/10, T1, 238,575 登録事象)

| ラベル | (ΔV,ΔE,Δβ₁) | 事象数 | 例外 |
|---|---|---|---|
| T1(三角挿入) | (+1,+2,+1) | 2,255 | 0 |
| T2(出芽) | — | 0 | — |
| T3_main(既存辺強化) | — | 0 | — |
| T3_fallback | — | 0 | — |
| REG(通常登録) | (0,0,0) | 236,317 | 0 |
| DYAD(種) | (+2,+1,0) | 3 | — |

T3 の内訳は別走(N=450, seed 5, T3, 631,162 事象)で取得:**T3_main が (0,0,0)×210,646、T3_fallback(実質 T1 型)は (+1,+2,+1)×1 のみ**。T3 は実効的に既存辺強化が支配し、新極も cycle もほぼ作らない(→ 飽和、窓ゼロ)。

### 4.2 不変性(18 seed-run T1 + 6 seed-run T2、全 N・全 seed 通算)

| 命題 | 結果 |
|---|---|
| **(P1)** T1 が常に (+1,+2,+1) | **成立**(全 seed-run で pure=True、通算 13,000+ 事象、例外 0) |
| **(P2)** T2 が常に (+1,+1,0) | **成立**(6 seed-run、946 事象、例外 0、全 run で最終 β₁=0=森) |
| **(P3)** REG が cycle を作らない | **成立**(全 run で新辺生成 0。reflection・床発火経路でも破れなし) |
| 台帳クロージャ(Σ Δβ₁ = 最終 β₁) | **全 run で一致**(捕捉漏れゼロ) |

**判定:** P1・P2・P3 はいずれも N=300/450/650 と 6 seed をまたいで例外ゼロで維持された。**cycle 生成は T1 の専売**が、大域状態・乱数経路を問わず成立することが確認された。

## 5. 結果:sink と収支(P4–P5)

### 5.1 sink の性格(P4)

- **連続忘却** `H*=(1-γ)`:辺を閾値割れさせて β₁ を減らす(N=450 の 2700 epoch-step 中、(0,−1,−1) 型が主)。ただし **ΔV は常に 0**——忘却はノードを殺さない(全 run で decay_dVnz=0)。cycle を漏らすが作らない。
- **孤立死**:ノードとその辺を除去し β₁ を減らす。除去の **ΔE/ΔV 比が T1 で 1.990(range 1.96–2.02)** ——次数 2 ノードの死。対照 T2 では **0.998(range 0.99–1.00)** ——次数 1 ペンダントの死。この比が転化則のノード次数を独立に分離する(T1=cycle 担持の次数2、T2=ペンダントの次数1)。

### 5.2 収支と計量窓の対応(P5)

窓産出 seed で、計量窓(METR 相)スナップショットの平均 β₁ を非窓スナップショットと比較した。

| N | 窓産出 seed-run | うち β₁(METR) > β₁(非METR) | gap の範囲 |
|---|---|---|---|
| 300 | 4 / 6 | 4 / 4 | +30 〜 +50 |
| 450 | 4 / 6 | 4 / 4 | +11 〜 +120 |
| 650 | 6 / 6 | 6 / 6 | +77 〜 +290 |
| **計** | **14 / 18** | **14 / 14** | — |

**すべての窓産出 run で、計量窓は β₁ の高い時間帯と一致した(反例ゼロ)。** gap は N とともに拡大する。計量窓は構造の恒常属性ではなく、**cycle 含有量が高く保たれた準定常領域**である、という §5.55.2 の描像に定量的裏付けがついた。

**監査状態(重要):** P5 は**相関**であり因果ではない。METR 相は ball 次元が読める(N(r)~r^d のフィットが成立する)ことで定義され、それが cycle を要することは示唆的だが、本検証では「β₁ 閾値が METR を*生む*」という機構は導出していない。窓の判定基準と β₁ の関係の形式化は **open**。

## 6. VED 公理への含意

**「細分」→「不可逆三角挿入」.** T1 が既存辺を消さないのは実装の癖ではない。K1 において登録は完了した区別であり、H は登録履歴として**加法的にのみ**蓄積される(全 run で REG は既存辺の強化のみ、削除は連続忘却と孤立死だけ)。完了した差 i–j を一事象内で抹消することはできない。ゆえに新極の挿入は置換ではなく**三角化**になる。荷重は「差だけがある(強形)」ではなく「**登録された差は不可逆に残る**」に乗る——これは §3.1(登録は区別の成立、成立に中間はない)と地続きで、substance の存在論的排除より守りやすい。

**窓条件の精密化.** §5.57.3 の「新極が cyclic core に載る」に機構が付く:**同じ登録事象が極と cycle を同時に鋳造するから載る。** さらに窓は静的な生成条件でなく、**T1 による cycle 鋳造(source)と、忘却の辺蒸発・次数2 death による cycle 消尽(sink)の収支が正味プラスで準定常に保たれる帯**、と読み直される(§5.2 の相関が支持)。

**梁3(最初の cycle はどこから来るか)のクローズ.** 純 T1 が cycle を生めるかは、教科書 subdivision なら否だが、実装は底辺保持ゆえに毎事象 cycle を内蔵生成する。別建ての閉包機構は要らない。ワーキングノート §8 の open「cycle 発生源」は本検証で解消され、「T1生成/T3閉包/代謝交替」という以前の分業図式は撤回される(T3 は v24 では閉包生成でなく強化・飽和)。

**残る open(§0 に従い名指し):**
1. **「間に入る = 次数2」の公理からの一意性.** なぜ次数 1(出芽)・0(面貼り)でなく 2 か。K1(1事象1量子)+ locality(1事象は既存の1つの差に作用)から次数 2 が落ちる、という論証は紙上にあるが(§5.57.4 注記)、公理からの一意導出は未完。**最も脆い梁。**
2. **収支↔窓の機構化.** §5.2 の相関を、METR 判定基準と β₁ を結ぶ機構へ。
3. **v24 モデル族への限定.** 転化則非依存性は否定済み(§5.57.2)。本検証は窓産出則 T1 の精密な性格づけであり、則をまたぐ不変量の主張ではない。

## 7. 再現手順

```bash
# 非摂動確認(元コードと window 出力がバイト一致することを確認)
python growth_v24.py       0.075 900 5,7,10 450 T1 > ref.txt
python growth_v24_betti.py 0.075 900 5,7,10 450 T1 > bet.txt
grep -E "^g=|window ep" ref.txt > a; grep -E "^g=|window ep" bet.txt > b; diff a b   # → 空(一致)

# per-event 署名(単一走の完全内訳)
python growth_v24_betti.py 0.075 900 5,7,10 450 T1        # T1
python growth_v24_betti.py 0.075 900 5     450 T3         # T3(fallback 比の確認)

# 再現性・収支キャンペーン(per-seed TSV を追記)
for N in 300 450 650; do
  PERSEED_TSV=repro.tsv python -u betti_repro.py 0.075 900 5,7,10,15,21,33 $N T1
done
PERSEED_TSV=repro.tsv python -u betti_repro.py 0.075 900 5,7,10,15,21,33 450 T2   # 対照
```

出力の各行:`[SEED]` に per-seed の署名純度・sink 収支・台帳クロージャ・β₁(METR vs 非METR)、`[VERDICT]` に走全体の不変性判定。`repro.tsv` に機械可読の per-seed 記録。

**設定:** λ=0.9, γ=0.075, 900 epochs, N∈{300,450,650}。乱数 seed は既定 rng(numpy default_rng)。
