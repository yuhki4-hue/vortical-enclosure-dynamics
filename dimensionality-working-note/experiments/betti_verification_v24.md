## 確定した主張

1. **cycle 生成源は T1 単独。** 生成的登録(新極を作る)のうち cycle を作るのは T1 のみ。
   T1 は一事象で極1つと cycle 1つを**必ず**同時に鋳造(Δβ₁=+1、2255/2255、例外なし)。
2. **T2 は極を作るが cycle を作らない**(pendant、Δβ₁=0、482/482)。→ 木、窓ゼロ。
3. **T3 は実効的に T3_main(既存辺強化、Δβ₁=0)支配**。fallback は 631k 中 1 回で無視可能。
   → 新極ほぼゼロ・cycle ほぼゼロ → 飽和、窓ゼロ。
4. **REG(全事象の ~99%)はトポロジー不変**。C の強化のみで極も cycle も動かさない。

## 予言を超えて見えた sink 側(窓産出 T1、seeds 5/7/10)

窓は「T1 が cycle を鋳造 ⇄ decay/death が cycle を漏らす」の準定常均衡だった:

- **DECAY**(連続忘却 H*=(1-γ)):2700 epoch-step 中 166 回で辺が閾値割れ → β₁ 減少
  ((0,-1,-1)×154, (0,-2,-2)×12)。**ΔV は常に 0**(忘却はノードを殺さない)。cycle を**漏らす**が作らない。
- **DEATH**(孤立死):(-1,-2,-1) が最頻(次数2ノードの死=2辺+1 cycle を持ち去る)。
  ΔE ≈ 2·ΔV の関係は、T1 が作るノードが次数2であることの傍証。
  一部 (-1,-1,0) は、decay が片脚を削って次数1化したノードが pendant として死ぬ経路。

**含意:** cycle の source(T1)と sink(decay の辺蒸発 + degree-2 death)が両方 β₁ で可視化された。
計量窓 = この収支が正味プラスで準定常に保たれる帯、という描像に定量的裏付け。
