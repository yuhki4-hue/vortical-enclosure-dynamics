§1何を問うているのか — 問いの転回

出発点はWorking Note I冒頭の一文——「次元は存在論ではなく、差分構造の有効記述である」——にある。「なぜ世界は3+1次元なのか」という存在論の問いは、まず「なぜ自由度の伸長が3(+1)で観測されるのか」(ノートI)へ、そして計器監査を経て「どのような差分登録の履歴が、計量として読める独立方向を持つのか」(ノートII)へと二段階で掛け替えられた。空間も座標も背景として仮定しない。あるのは「差がある」という最小の事実だけで、そこから 差分 → 二項関係 → 登録 → サイクル → 計量可読性 → 次元、という梯子を一段ずつ、測定で確かめながら登る(梯子の全体は§6・図9)。なおノートIは、ノード間の距離構造が要する関係的次元(基空間)と、ノード内部の自由度である状態的次元(ファイバー)を別の棚として早期に分離しており、SU(3)の「3」と空間の「3」を同一視する誘惑はこの区分で封じられている。

この一連のノートを特徴づけるのは主張よりむしろ監査の運用である。すべての記述は「測定事実/純粋帰結/構成原理/予想」に区分され、実験は実施前に設計・判定基準ごと登録され、自分自身の過去の読みが繰り返し棄却・降格される。ノートIでは16版の連続失敗の測量と「3」の棄却が(§2)、ノートIIでは7項目の棄却台帳が(§5末・表5)、その運用の証跡である。現在残っている主張は、この選別を生き延びたものだけである。

§3実験装置 — 減衰する台帳と、ひとつの更新規則

数値実験系(v24系)——前節の軌跡の到達点——は次のように要約できる。ノードは「登録項」、辺は「登録された差分」で、各辺は流束 C_ij を持ち一様に減衰する。発火した辺の流束は規則に従って他の辺へ再分配され(=再給餌)、給餌が減衰に追いつかない辺は支持閾値を割って消える。つまり登録とは一度立てたら消えない旗ではなく、流れによって維持され続ける準安定状態である——これはコード監査から得た確定的な読みである。

成長はただ一つの更新規則で起きる。T1=不可逆三角挿入:既存の辺を保存したまま、新しい極をその両端に接続する(図3)。一回の登録事象が、新ノードとサイクルを同時に、正確に ΔV=+1, ΔE=+2, Δβ₁=+1 だけ生む。この「正確に1ずつ」という帳簿的恒等式が、後で重要な罠(§5-5)にもなる。

もう一つの鍵は流束の逃がし方の規則である。directed(有向)台帳では、発火した辺自身とその逆向き辺への還流が禁止される。つまり辺は自分で自分を養えない。ここから「持続する登録は、系を巡って戻ってくる閉じた再給餌回路を要求するのではないか」という本ノートの構造仮説が生まれた。主要な用語を表3にまとめる。

§5ノートIIでわかったこと — 7つの発見

5-1「可読の窓」の正体は、フィットの質ではなく測れる幅だった 確定

v24で「METR相」と呼ばれていたものは、コード監査の結果、計量が読める証明ではなくball次元フィットが成立する残余クラス(BSW)だと判明した。しかも v24.1 の再読解で、窓の開閉を決めているのはフィットの良し悪しではない(成立時のR²は常に0.975以上と高い)。決めているのは使える半径点数 npts が最小条件をまたぐか——つまり「どれだけ広い距離レンジが測定に使えるか」という幅の閾値通過である。系は常に閾値近傍に滞在し、窓は緩やかに開くのではなく揺らぎで横断される。以後、頑健な主張は min-npts≥5 を生き残る窓に限定された。

5-2登録の「寿命」と構造の「可読性」は、別の法則で決まる 確定(v24.3)

directed と symmetric は実は2つの因子——自己給餌の可否(発火辺が自分を養えるか)と逃口の成形(流束を片側に集中するか両側に分散するか)——を同時に変えていた。v24.3はこれを2×2の4セルに分解した(図4)。

5-3読めるのは成長期ではなく収縮期 — しかも収縮は二相ある 確定(測定) 浄化仮説は棄却

v24.2で意外な事実が出た。可読の窓は系が成長しているときではなく、ピーク後の緩やかな収縮期に集中して開く(滞在率 73.1% vs 21.5%)。当初の説明候補「収縮=弱い構造が蒸発して純化するから読める」(浄化仮説)はオフライン検定で棄却された:蒸発の勢いと窓の開きは無相関(corr≈−0.01)で、しかも硬化率 h はむしろ収縮期に下がる。窓が開くのは蒸発の「勢い」ではなく、薄く・伸びた「状態」においてである。

さらにv24.2e以降、収縮は一枚岩ではないことがわかった。h(t) はU字を描く——まず幾何が帳簿から剥がれる shedding(脱ぎ)、次に h が回復する consolidation(締固め)(図5右)。そして相分類器(2b)で層別すると、頑健な可読性は締固め相に最も濃縮していた(図5左)。

5-4帯は消えない — 系は「呼吸」し、収縮のたびに読める 確定(n=1走行+呼吸内再現)

では可読の帯は最終的にどうなるのか。選択肢は3つあった:(a) 系とともに消滅する、(b) 定常状態に落ち着く、(c) 成長と収縮を繰り返しながら続く。4000エポックの超長走行(2c)の判定は BREATHE(呼吸継続) だった(図6)。

5-5「サイクルの総数」は幻だった — β₁(H) ≈ V + const 確定(恒等式)

初期の有望な相関「サイクルが多いほど読める(β₁↑ → BSW)」は、v24.2で帳簿の恒等式に還元された。T1は全事象で正確に dV=+1, dβ₁=+1 を刻むため、β₁(H) は V+const、つまりただの系サイズの代理量である。サイクル総数と可読性の相関は、サイズとの共線性にすぎなかった。これにより中心仮説L6→L7は「サイクルが多いほど読める」から「どのサイクルが運搬支持へ硬化し、持続するかを読める幾何が決める」へ再定式化された。検証計器も総数から、β₁(S)系・サイクル寿命・overlapへ移された——これがキャンペーンAである。

5-6可読状態とは、サイクルが「解けて」選択保存されている状態 仮説+初の陽性信号

キャンペーンA(cycle個体追跡)は、三角挿入TDと長周期挿入TL2の対照でサイクルを個体レベルで追った。結果は三つ。

  • 寿命差は辺数比でほぼ説明される。サイクル寿命中央値の比 144/190=0.76 は周長比 3/4=0.75 と一致——サイクルは「構成辺がそれぞれ独立ハザードで死ぬ」帰無モデルから大きく外れない。「TLは脆弱なサイクルを作る」懸念は棄却。
  • L6→L7に初の陽性信号。頑健に読めているステップでは、サイクルの数や年齢は変わらないのに、overlap(サイクル同士の辺共有)連結性が有意に低い(ov_lcc 中央値 0.049 vs 0.124)。可読状態はサイクルが多い状態ではなく、サイクル同士が解けている状態である。
  • consolidation相はサイクル生存の「抑制場」。repair(同一サイクルの復硬化)か turnover(入れ替わり)かという二分法は、年齢別Kaplan–Meier補正で「相変調ハザード」に解消された(図7)。

5-7「何次元か」はまだ言えない — 3.43は撤回、忠実較正で「3のやや下」 3.43次元は撤回 次元言明は条件付きのみ

directed頑健帯のball次元読み d_cal の中央値 3.43 は、90%が3D格子アンカーの上限を超える「外挿値」だった。監査の結果、較正アンカー自体が周期境界・系サイズ・辺重みの一様性に強く依存しており(重みの不均一だけで読みが 1.97→2.54 動く)、規約を宣言しない d_cal は次元主張に使えないと判明。成長グラフに忠実な規約(非周期・ステップごとのV整合・経験的辺重み)で再較正すると読みは大きく動いた(図8)。

§6概念の梯子と、中心仮説の現在形

ノートIIはこの依存関係の梯子(L系列)の上に組まれている。ノートIのK系列(離散登録→コンパクト化→巻き数の整数化→絡み→3+1)がこの分野で登ろうとする「縦の道」だとすれば、L系列はその成立条件を横から監査する足場である——K6(絡みが3を選ぶ)に賭ける前に、L7(計量可読性)を固めるという順序が自覚的に選ばれている。各段の現在の監査状態を付す。

以上を束ねた中心仮説の現在形(ノート§11の圧縮)は次のとおり。

差は二項を要する。背景容器を持たない新しい差は、既存差に対して登録される。有向台帳では自分で自分を養えないため、持続する登録は系を巡る閉じた再給餌回路を要求する。可読の帯は成長期でなく中間収縮帯に開く。それを支えるのはサイクルの数ではなく、どのサイクルが運搬へ硬化し、持続するかである。——流束の閉回路が持続登録を、硬化したサイクルが計量可読性を担うとき、差分構造は計量として読める可能性がある。

この三文のうち、前半は純粋構成とコード帰結、中央は測定事実と未分離の要因、後半は検証すべき仮説——という区分までがノートに明記されている。

§7まだ開いていること・次の一手

開いている主要問題:

  • L1→L2(内部アドレス原理)は依然として最も痛い急所。孤立項の内部アドレス構成が示されれば弱まる。登録概念の自己適用問題(「登録済み/未登録」の区別自体が差分を使う)も未決。
  • BSWはMRWの何なのか(必要条件・十分条件・相関物?)。MRWの4条件のうち、接続性・経路冗長性(0.73)・時間的持続(950ep)には正の証拠があるが、「有限な不整合」だけは構成上自動成立のため未検定。§10の帰還条件4(独立二計器の次元整合)も未着手。
  • campAの残件: TSセル(細分対照)が未走行でA3判定は未決。TL2の異パターン(若く少ないサイクル)の解釈保留。s33の逆転例、seed異質性、呼吸の減衰(n=2)も未解決。
  • 相関どまりの発見:「可読=解れ」「consolidation=選択保存」はいずれも観測的合流であり、因果は未確定。

ノートが自ら指定している次の一手(§12優先順):

  2. 小規模較正——既知グラフ(木・格子・ランダム・小世界)でBSW判定器とMRW候補軸を独立検証(判定器の反証条件 §9.7)。
