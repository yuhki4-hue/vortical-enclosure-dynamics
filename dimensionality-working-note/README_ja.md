## 1. 問いの転換:次元は容器ではなく観測されたランク

> **次元は存在論ではなく、差分構造の有効記述である。**

本ノート全体はこの一文を前提として書かれている。§0 の監査規律(「導出された」の三条件)も §9 の自己監査(「決して完結しない」)も、この一文の態度を個別の場面に適用したものにすぎない。次元を実体として問う限り本ノートの議論は循環するが、差分構造に対する有効記述として問う限り、以下の議論はすべて訂正可能な足場のまま前進できる。

物理は 3+1 次元を観測する。VED の公理は「差がある」のみであり、次元数はどこにも仮定されていない。したがって次元はもともと **フリー** である。

問いはこう転換される:

> なぜ次元は 3+1 か → **なぜ自由度の伸長が 3(+1)で観測されるのか**

次元は差分が伸びた方向の観測されたランクであり、伸長自体は任意ランクに起こりうる。観測されるのは **持続した** 構造だけである。ゆえに「観測次元」とは「差分構造が持続可能なランク」の別名になる。

**監査状態:** 問いの再定式化。主張ではない。

## 1.5. 次元の二つの型:関係的次元と状態的次元

一般の科学言説(物理・数学の運用レベル)では、「次元」という語が二種類の異なる概念を無自覚に往復している。VEDの語彙で明示的に分離しておく。

**関係的次元(ユークリッド型/extensive/底空間型)**
ノード**間**の距離構造(d_ij = −log S_ij)を等長に実現するのに要する独立方向の数。外側的・関係的。ファイバー束の言葉で言えば **底空間** の次元にあたる。§4〜§5(K5〜K7)で扱う「渦が持続できる独立方向の数」は完全にこちら側であり、動力学的な選別(絡みの位相保護)によって決まる。

**状態的次元(ヒルベルト型/intensive/ファイバー型)**
一つのノード**が**内部に保持する状態の自由度の数。関係の話ではなく、単一の点が「何を保持できるか」の話。ファイバー束の言葉で言えば **ファイバー** の次元。ゲージ内部空間、状態ベクトルの成分数などがこちらに属する。

**一般の混同のされ方**
場の理論では本来この二つは厳密に分離される概念だが(底空間 vs ファイバー)、余剰次元と内部対称性の次元が同列に語られたり、ヒルベルト空間の次元と空間的次元が地続きに扱われたりする場面は運用上多い。区別する語彙はあるのに、しばしば溶ける。

**次元の一般定義(暫定・本ノートの立場)**
> 次元とは、登録された差分のうち、代数的制約または動力学的持続条件によって独立な区別として生き残った方向の数である。この定義は関係的次元・状態的次元のどちらにも中立に適用されるが、**両者は異なる棚に属する量であり、数値が一致しても直ちに同一視してはならない**。

以下の残差の棚卸し(§2)は、この区別が徹底されていなかった箇所の記録でもある。

## 1.6. さらなる抽象化:差分の所在による分岐、情報次元の横断性

§1.5 の二つの型は、実は一つの定義の特殊化として書き直せる:

> **次元 = 差分が独立性を保持する方向数。違いは「何の差分か」だけ。**
> 関係差分(ノード間の差分、C_ij そのもの)→ 関係的次元
> 状態差分(ノード内の差分、e_i など)→ 状態的次元

これは §1.5 の一般定義をより基底に還元したものであり、二つの型を廃止するのではなく、**両方が同じ一行から出る特殊ケースである**ことを明示する。

**この還元が §5.5 の発見と噛み合わせると、非対称性が一つ見つかる**
`closure_energy.tex` の e_i 構成式(⟨e_i,e_k⟩ = ΣA_ijA_kℓS_ijS_kℓS̃_jℓ)および ρ_i = Σ_j C_ij はいずれも、**状態差分を関係差分の射影・要約として構成している**。現行の VED 定式化では、状態差分は独立な一次的差分としては現れず、常に関係差分(C_ij)からの導出物として登場する。これは欠陥ではないが、監査上の観察点として記録する:**関係的次元が基底で、状態的次元はその上に射影として乗っている**、という非対称性が現状の理論にはある。もし将来、状態差分が独立に振る舞う場面(関係差分に還元できない状態変化)が理論の中に現れれば、この非対称性は破れ、再検討が要る。

**情報次元:第三の棚ではなく、二棚を跨ぐ操作**
物理差分(関係的であれ状態的であれ)が **情報として再利用される方向の数** を情報次元と呼ぶなら、これは関係的次元・状態的次元のどちらとも並ぶ第三の種類の次元ではなく、**両者の上にかかる横断的な操作**(射影・拘束)として位置づけられる:

$$\text{物理差分} \;\xrightarrow{\text{情報拘束}}\; \text{独立方向}$$

この読みは IFGT の射影語彙(Φ_ext ≡ Φ_net、意識篇の射影プリミティブ)と自然に接続する。情報次元とは「登録済みの差分構造が、射影を経てどれだけ独立方向を保ったまま再利用可能か」の測度であり、関係的次元・状態的次元のどちらの上にも定義できる横断的関数、という位置づけが今のところ一貫している。

**監査状態:** 概念的統一(紙上)。§1.6 全体はまだ定式化(方程式)を持たない。上記の非対称性の観察は §5.5.1/§5.5.2 の事実確認に基づく。情報次元の厳密な定義(射影演算子の具体形)は **open**。IFGT 側の Φ_ext ≡ Φ_net との接続も、用語の類似に基づく仮の橋渡しであり、構造的な一致は未検証 — 井戸(§7 と同型のリスク)に注意しながら進める。

## 3. 中核提案:登録の離散性(公理の系として)

### 3.1 導出

運動が幾何として構成可能であるためには、関係の項になる **完了した登録** が必要である。登録が連続——あらゆる登録が永遠に「途中」——なら、関係の項が存在せず、幾何は立たない。運動は幾何になれず未分化の流れに留まる。

これは公理から次の形で従う:

> 「差がある」とは区別が成立していることである。区別に程度はない——半分だけ区別されたものは、まだ区別されていない。登録とは区別の成立であり、成立に中間はない。**ゆえに登録は離散である。**

これは独立の公理ではない。公理「差がある」を登録の側から読んだ **系(corollary)** である。公理は一つのまま。

### 3.2 直ちに従う再解釈

- **H は登録イベントの列**になる。連続的な H(t) は、イベントレートが速い極限の粗視化記述に格下げされる(既存の連続式は全て有効記述として無傷で残る)。
- **背景時間 t が不要になる**(§2.3 の残差の解消)。根源的なのはイベントの順序と数のみ。dτ/dt = ρ は「登録イベント 1 回につき τ が 1 目盛進む」の連続極限として導出される式になる。
- **χ = λρH に最小増分**が入る。累積露出 χ は離散通貨で支払われる。
- **ツェノン問題の解消**(副産物):運動は連続空間の通過ではなく登録の更新列であり、無限分割が生じない。

### 3.3 hbar との合流(狙わずに閉じた接続)

stochastic-quantization で `hbar_eff = a² S_Δ`(差分場の揺らぎ強度)は導出済み。登録が離散なら、hbar は **登録一回分の最小通貨** という解釈を自然に得る。「なぜ作用に量子があるか」への VED の答えが「登録に中間がないから」になる。この接続は本ノートの導出過程で設計されたものではなく、離散登録を入れた時点で自動的に閉じた。

**監査状態:** §3.1 は系としての導出(紙上)。§3.2 は §3.1 からの直接の帰結。§3.3 は解釈の合流であり、独立の検証(hbar_eff の最小増分がイベント単位と一致するかの数値確認)が未実施 — **open**。

## 5. グラフ内在的絡み数:定義の候補と淘汰の記録

型 1(安定性選択:任意ランクに伸び得るが持続するのは 3 のみ)を検証可能にするには、埋め込み座標なしの絡み数が要る。判定基準:(a) C, ρ, H / χ, a のみで書ける、(b) 再アドレス不変、(c) 離散的に絡みを区別し log の局所更新で保存。

**候補 A(相互循環 / 離散 Biot–Savart):** γ₂ が誘導する反対称 exposure を γ₁ で周回積分。ゲージ不変だが、伝播則が D(transport)に依存し、絡みの定義に先立ってランク情報が混入する。**保留(半歩井戸)**。

**候補 B(組合せ交差符号):** ノードでのリンク巡回順序から交差符号を定義。巡回順序 = 局所平面性 = 次元の密輸。**却下**。

**候補 C(再アドレス障害 → 緩和障害へ修正):**
- 初版:「φ を動かして F_p² を最小化、残差を絡みとする」— **紙上で欠陥発見**:F_p はループ和ゆえ再アドレス不変であり、φ の探索は空回りする。定義として死んでいる。
- 修正版:緩和をゲージ軌道上の探索ではなく **τ に沿う Langevin 緩和(閉包動力学そのもの)** に差し替える。γ₂ の χ を凍結拘束し、系を流し、全系 F² 総和が落ちきるかを見る。**絡み = 動力学が到達できない残差床**。
- 副産物:「ループの内部」(Jordan 曲線問題)が定義から消える。床は全系で測ればよく、定義は γ₁↔γ₂ 対称になる。

## 5.5. 第二ルートの発見:S̃ スペクトルによる直接計算(グラム行列ルート)

本節は K5〜K7(絡みルート)の**代替ではなく並走する第二ルート**の記録である。発見の経路自体が監査情報を含むため、経緯ごと記す。

### 5.5.1 発見の経緯(§2.2 の残差の最終処理)

§2.2 で「e_i の外積が 3 を密輸している」と疑った。その監査を進める過程で `closure_energy.tex` に e_i の**構成的定義**が既に存在することを確認した:

$$\langle \vec e_i, \vec e_k\rangle = \sum_{j,\ell} A_{ij}A_{k\ell}\,S_{ij}S_{k\ell}\,\tilde S_{j\ell}$$

原文に "No external embedding space is assumed" と明記されており、e_i は埋め込みベクトルではなく、**この内積(グラム行列)が定義する内在的な対象**である。したがって:

- e_i の住む空間の次元は仮定される数字ではなく、**グラム行列 M_ik のランクとして計算される出力**。
- §2.2 の「密輸」疑惑は最終的に**実体のない残差**と判定される。外積(×)は面積を出すための表記上の便宜であり、面積概念自体は任意次元でくさび積のグラム行列式から定義できる。理論が埋め込み次元 = 3 を要求している箇所は存在しない。
- **残る作業**は疑惑の解消ではなく、未計算量の計算である(→ 5.5.2)。

### 5.5.2 分解と、次元問題の線形代数への還元

F_{ji} := A_{ij}S_{ij} と置くと、グラム行列は

$$M = F^\top \tilde S\, F$$

と分解され、直ちに

$$\mathrm{rank}(M) \le \mathrm{rank}(\tilde S)$$

が従う。よって **底空間の次元問題は S̃(C_ij の対称成分が作る核行列)の固有値スペクトルの実効ランクの問題に還元される**。S̃ は距離構造 d_ij = −log S̃_ij の由来そのものであり、熱核・ガウス核型の核行列の固有値減衰から有効次元を読む手法(スペクトル次元と同種)は標準的で計算可能。

> **第二ルート:観測空間次元 = S̃_jℓ の固有値スペクトルの実効ランク**

このルートの特長:
- K3〜K6(コンパクト化・絡み数、いずれも予想段階)を**一切経由しない**。
- 既存のシミュレーションデータ(a_ij, χ, S)にそのまま適用可能。S̃ を対角化して固有値分布を見るだけで、即座に試算できる。
- K6 の数値プロトタイプ(§8-3)より遥かに軽い。

### 5.5.3 二ルートの関係と監査上の意味

| | ルート I(絡み) | ルート II(スペクトル) |
|---|---|---|
| 機構 | 位相的保護:渦が消えずに持続できるランク | 線形代数:log ネットワークが誘導する内積の実効ランク |
| 依存する予想 | K3, K4, K5, K6 | なし(C_ij の定義のみ) |
| 答える問い | なぜ **その** 次元で持続するのか(動力学的理由) | 今のネットワークは **何** 次元か(記述的測定) |
| 状態 | 予想の鎖 | 未計算の計算問題 |

二ルートが同じ値(3)を出せば強い相互検証になる。食い違えば、どちらかの定式化(あるいは「次元」の同定)に誤りがあるサインとなり、それ自体が診断情報。**ルート II を先に走らせるのが順序として正しい**——予想を含まない方から測るべきである。

### 5.5.4 SU(3) の「3」との関係の最終整理(フラクタル性検討の帰結)

単一公理の理論が無関係な複数プロセスを立てるのは不自然、という動機から「同じ演算のスケール違い(フラクタル性)」を検討した。結論:

- **底空間の次元** ← S̃ の固有値スペクトル(**線形代数的**操作)
- **SU(3) の 3** ← 最小閉包が 3 ノードであるという事実(**グラフ組合せ的**操作、`symmetry_geometry.tex` の ψ = (e_1,e_2,e_3) は 3 ノードのラベルであり、e_i の住む空間の次元と論理的に独立)

同じ演算のスケール違い、ではなかった。正確には:**単一の生成物 C_ij に対する、二つの異なるが共に自然な問い(ランクとサイクル長)**。仮定は増えていない——公理一つ、生成物一つ、問いが二つ。§1.5 の型区分(底空間型/ファイバー型)はこの整理によって維持され、かつ両者の共通の根(C_ij)が特定されたことで「無関係な棚」ではなく「同根別枝」として位置づけ直される。

また、非退化性の要件そのものから安価な下限 **d ≥ 2** が独立に従う(3 点が面積を持つには最低 2 独立方向が要る。`triangular_closure.tex` の退化レジーム記述に既に含意)。ルート I の d = 3(予想)の手前に、この確立済み下限を土台として明示しておく。

**監査状態:** 分解 M = FᵀS̃F は紙上導出(初等)。スペクトル計算は未実施 — **open、ただし即実行可能**。

### 5.8.3 §5.7.4 の自己監査条項の発動:枠組みの欠陥

事前登録した警告——「v4 でもヌルなら、正典項の中から次を探す前に、成長則自体の枠組みを疑うこと」——に従い枠組みを点検した結果、**公理違反が一つ発見された**:

> **固定されたノード集合(N=300)を最初から全て与えていた。**

これは、差分が一つも登録される前から存在し、探索床 η によって任意に到達できる「事前に用意された全アドレス空間」である。Phase 4 が「物理を持たない」と示した当のもの(アドレス)を、登録に先立って無料で配布していた。近道が消せなかった根本原因の有力候補:**近道の行き先(未使用の自由アドレス)をモデル側が供給していた**。

これは本ノート冒頭の一文——「次元は存在論ではなく、差分構造の有効記述である」——を、**モデル自身が破っていた**ことの発見でもある。固定ノード集合は容器(存在論)の密輸だった。v1〜v4 の四連ヌルは、この密輸の上で走っていた。

### 5.8.4 v5 の枠組み(設計のみ、未実施)

ノード集合を固定しない生成型に変更する。登録イベントが取りうる形は二つのみ:

- **(a) 強化:** 既存構造の隣接リンクに H += 1
- **(b) 分岐:** 既存ノードから新ノードが差分として生まれる(新ノードの初期接続は親ノードのみ)

全対全の可能性空間が最初から存在しないため、近道は「作られなければ存在しない」。因果集合の sprinkling(背景多様体に点を撒く)とも異なる、背景なしの純粋生成型。測定対象:成長するネットワークの d̂(t) と、(a)/(b) 比率・減衰 γ への依存性。

3. **pb 大(0.3–0.9):再断片化(gc ≈ 40/900)——ただし原因は減衰ではなく不動点崩壊**。

### 5.9.3 中心的発見:疎構造は不動点を生き延びられない

チェーン上のノード(隣接 2、H = 1)で不動点方程式を解析的に評価:

$$\rho = 2(1 - e^{-0.05\rho}) \approx 0.1\rho \;\Rightarrow\; \rho^* = 0$$

**λρH の積が閾値を超えない疎構造は、自己言及的選択そのものによって存在から脱落する。** 生き残った gc ≈ 40 は密な塊のみであり、密ゆえに d̂ = ∞。これは計器のバグでもモデルの欠陥でもなく、C_ij 方程式の正直な帰結である。

### 5.9.4 帰結の裏返し:ルート I の自発的再出現

有限次元の幾何とは疎な構造(有界次数)である。疎構造が不動点を生き延びる唯一の道は **H が大きいこと=同一リンクの反復的再通過**(H = 100 のチェーンなら ρ = 2(1−e^{−5ρ}) → ρ* ≈ 2 で自立)。

「同じリンクの反復的再通過による持続」は**渦の定義そのもの**(flow の再帰的・自己参照的持続、rank 4)。

> **ルート II の成長モデルを正直に走らせた結果、その故障診断の中から、ルート I(渦・持続的循環)が「有限次元が生き残るための必要条件」として自力で再出現した。** K6 を仮定として投入したのではなく、不動点方程式の側から要請として出てきた。§5.6.3 では三本の線(K1・ルート I・ルート II)の「収束」と書いたが、今回は収束ではなく**合流**である。

## 5.12. v8 の記録:飽和障壁の二重ヌルと、直列性=時間の容器の発見

実施日:2026-07-06。コード:`growth_v8.py`(v8.1b パッチ含む)。§5.11.4 の均質化機構探索を実施した。

### 5.12.1 実装した候補(いずれも正典由来)

統一方程式の二項を均質化機構の候補として実装:
- **−κ_B/(C_max−C)(非閉包障壁)→ 飽和登録:** ΔH = (1−C)。飽和リンクは新しい差を登録できない(差が既に最大なら新しい差は差として立たない — 公理的に自然)。加えて分岐確率を局所飽和度に比例(差分がフロンティアへ溢れる想定)
- **aΔ(1−C/C∗)(拡散項)→ 流束移動則(v8.1):** 移動確率 p ∝ C_wj·(1−sat_j)。流れが空き容量のある方へ向かう

### 5.12.2 結果:二重ヌル

| 実装 | d_cal(seed 3 本) | CV(均質性、小さいほど均質) |
|---|---|---|
| 対照(v6 則) | 0.67〜0.71 | 0.68〜0.89 |
| 飽和登録+飽和分岐 | **0.08〜0.11(星型化)** | 0.74(不変) |

飽和分岐は「分岐=ウォーカーの現在地=コア」のため、飽和コアに新ノードがぶら下がる巨大ハブを生成した。流束移動則も CV を悪化させた。

### 5.12.3 診断:直列性が不均質性の根、全順序=時間の容器

二通りの正典項実装が共に失敗したことで、実装細部より深い診断に到達した:

> **単一ウォーカー=登録イベントへの全順序(total order)の賦課=グローバルな逐次時計の密輸。**

不均質性は「最近ウォーカーがいた場所への偏り」であり、これは直列性そのものから生じるため、どんな局所則を足しても消えない。理論との食い違いは明確:Vol.1 の τ は**ノードごと**に進む(dτ_i/dt = ρ_i)。時間は各所で局所的に進むのであって、単一のグローバル時計に沿って一箇所ずつ進むのではない。§2.3 で背景時間 t を理論から追放しながら、**モデル内にグローバル逐次イベント順序という形で t を再密輸していた**。

これは §5.8.3(固定ノード集合=アドレスの容器)と対をなす発見である:**空間の容器に続き、時間の容器**。登録の順序は本来、半順序(因果集合的)でなければならない。

### 5.12.4 substrate universality への理論的回答候補

> **均質性 ← 登録の並列性。「差がある」は世界のどこか一点で順番に成立するのではなく、至る所で同時に成立する。直列登録の系は原理的に不均質。**

これが正しければ、open problem #2 は動力学の詳細ではなく**登録の順序構造(全順序か半順序か)**の問題に還元される。整合する事実:元の stochastic-quantization の Langevin シミュレーションは並列更新であり(固定幾何上だが)均質だった。生成的幾何+並列登録を併せ持つモデルはまだ存在しない — それが v9。

**監査状態:** §5.12.1–5.12.2 は実測記録。§5.12.3 は診断(直列性→不均質の必然性は、二重ヌル+理論との整合から推論されたものであり、形式的証明はない)。§5.12.4 は理論的回答候補 — **open、v9 で検証**。

### 5.14.3 帯内閉包スイープ:全滅と診断

帯内 3 セル × pc ∈ {0.02, 0.05, 0.1}(LAG=6、seed 2 本)で固定ラグ閉包を追加した結果、**全条件で窓消失**。gc ≈ 0.95 で連結は維持されているため、これは飽和ではなく **small-world 型崩壊**(直径圧潰)である — 現行の相分類器はこれを SAT と誤ラベルするため、分類器に第四ラベル(SW:窓なし・連結・C 中間)が必要。

**v6 で効いた固定ラグが帯内で壊れる理由:** v6(直列・λ=1)ではウォーカーが強い強化でコアに局在し、log の「6 ステップ前」は計量的にも近かった。帯内(λ 小)の流れは拡散的で遠くまで動くため、「自分の log の 6 ステップ前」が計量的に遠方になり、さらに一度張られた弦の上を後続の流れが移動できるため次の弦はより遠くを繋ぐ — **再帰的ショートカット形成**。ステップ数で固定したラグは計量的ループサイズを固定せず、実質的に v6 の 'window' 閉包(ランダム長 → 崩壊)へ退化する。

### 5.14.4 剥き出しになった問い:ブートストラップ問題

> **閉包は計量的に局所でなければならない。しかしその計量は、いままさに閉包が建てようとしているものである。計量を参照せずに、計量的局所性をどう実現するか。**

設計候補(未実施):**strong-tie 閉包** — 流れが参照できるのは自分の log と局所 C 値のみ、という制約の中で、「C 値の高い経路だけを辿って到達できる相手にのみ閉じる」。d = −log C ゆえ、強く登録された近傍は**定義上**計量的に近い。C 自身が局所性の判定器になるため、計量を外から参照しない — ブートストラップを回避する候補。

## 5.19. v12 の設計固定(実施前登録):閉包の分岐転化(細分)

記載日:2026-07-06。**本節は実施前に固定された設計であり、実行後に遡って変更しない**(§5.15/§5.17 と同形式)。

### 5.19.1 転化則(パラメタフリー)

流れが閉包を試みるとき、標的リンクの C が高いほど登録は阻まれる(ΔH = 1−C。残りの C が「登録されなかった差」)。この阻まれた分を捨てずに転化する:

> **閉包試行は確率 (1−C_wt) で通常の閉包として登録され、確率 C_wt(阻まれた分)で分岐に転化する。**

確率が C 自身であるため新しい外部パラメタはゼロ。正典接地:非閉包障壁(閉じきれない残差が流れを逸らす)、「差が差を生む」。

### 5.19.2 転化先(主設計判断):細分

新ノードは **w と標的 tgt の両方に接続**する — 新ノードが**阻まれた閉包の上に**生まれ、閉包は直結ではなく新ノード経由(w–新–tgt)で完成する。

これは**細分(subdivision)**である:飽和したループの再強化(0 次元的な重み増加)が、新しい頂点の創出(次元を上げうる構造追加)に置き換わる。「閉じ損ねた分が世界を広げる」が、文字通り「ループが太らずに面へ細分されていく」形を取る。対照案(w の子としての単純分岐)は採用しない。

### 5.19.3 診断パネル追加

既存パネル(§5.17.2-4)に**サイクルランク E−N+1**(ループ密度)と**転化イベント数**を追加。細分がループを実際に作っているか・潰しているかを直接観測する。

### 5.19.4 判定基準と失敗モード(事前固定)

**成功:** 帯内 METR 維持、**d ≥ 1.8**(新ベースライン 1.63 + 3σ 超)、f09 がベースライン(0.40)から悪化しない、サイクルランク > 0(ループの実在)。

**失敗モードと解釈規則:**
- **(i) 暴走インフレ:** 転化過多で NMAX に即到達、縁が木化して d が 1.6 以下へ後退。署名:ノード数早期飽和+サイクルランク低。解釈:転化に減衰側の対抗(細分ノードも忘却で死ねる)が必要 — 出生と死のバランス設計へ。
- **(ii) 飽和残存:** 細分でも medC > 0.9。解釈:飽和源は閉包ではなく移動強化が主犯 — 登録予算の大域再設計へ。

## 5.25. 理論的解決:流れの脱物象化(紙上検討の記録)

記載日:2026-07-06。§5.24.5 の問い「流れの生死は何が決めるか」への紙上の回答。

### 5.25.1 診断:第四の容器の正体はエージェント抽象

生成列において流れは rank 3 の**派生物**である:差分 → C_ij → 勾配 → 流れ。勾配があるところに流れがあり、勾配が消えれば流れも消える — 生死を管理すべき保存トークンではない。

v5 以降のモデル族は流れを**エージェント(ウォーカー)として物象化**してきた。さらに移動則は p ∝ C(重み比例)であり、VED の流れ(∇ρ 駆動の輸送)ですらなく、ただの拡散粒子だった。第四の容器の正体は「流れの保存則」より深く、**エージェント抽象そのもの=流れの物象化**である。皮肉な系譜:エージェントは第一の容器(固定ノード集合)を外すために v5 で導入された道具だった — 一つの容器を外す道具が次の容器になっていた(冒頭の一文の四度目の実証)。

### 5.25.2 解決:勾配駆動リンクイベント

流れをエージェントにせず、登録をリンクレベルの一時的イベントに戻す:

> **リンク (i,j) の登録イベント発火レート ∝ |ρ_i − ρ_j|(局所活性の差)。**

「差がある」→ 差があるところで登録が起きる — 公理の動力学的直訳。帰結:

1. **死が自動化する:** ρ が局所均衡した領域では発火レート → 0、減衰のみが働き、リンクが薄れノードが退場。**死=局所平衡=無差別化**。死の規則を別途書く必要が消える。
2. **並列性がエージェントなしで完全になる:** 全リンクが独立に発火 — 元の Langevin 描像(Phase 1–4)への回帰。v9 が欲した半順序の並列登録が迂回なしで実現。
3. **相互不死が原理的に不可能:** 交通を維持する常駐者が存在しない。均衡域は誰にも保守されず、正しく死ぬ。
4. **τ との締結:** dτ_i/dt = ρ_i より、発火レート ∝ |ρ_i − ρ_j| は「**局所時計の進み方が食い違う場所で差が登録される**」— K8(時間の向き付け)と一本につながる。

**監査状態:** 紙上の理論的解決。数値検証は v15(§5.26)— **open**。

## 5.29. 理論的解決:第六の容器= C の瞬時平衡化(紙上検討の記録)

記載日:2026-07-06。§5.28.4 の三候補の潰し合いの記録。

### 5.29.1 潰し合い

- **(a) 拡散項:棄却(主機構として)。** 新生リンクの熱は C の動力学経由ではなく、C = 1−exp(−λρH) を通じて ρ から瞬時に入る。熱いポケットでは近傍も熱く、均しても冷えない。パラメタ a, C∗ の新規導入も減点。補助項として後日再訪可。

### 5.29.2 第六の容器

統一方程式 ∂C/∂t + ∇·J_C = aΔ(1−C/C∗) − ΓC − κ_B/(C_max−C) において **C は自分の時間発展を持つ変数**であり、C = 1−exp(−λρH) はその**平衡関係**(不動点)であって定義式ではない。v5 以降の全モデルは、毎エポック C を不動点として瞬時に平衡化させてきた。

根本原因は実装規約:ρ の忘却に γ(遅い層の減衰率)を流用し、κ = γ とも置いた — **fast/slow 分離を実装するはずの設計で、両層に同じ時計を配り、分離を自ら潰していた**。ρ は速い層であり、イベント間の時間スケールで緩和しなければ勾配が無制限に蓄積する。

> **教訓:時間スケール分離は簿記ではなく、安定化装置そのものである。** 速い層と遅い層が同じ時計を持つ系は、亜臨界(全死)か超臨界(爆発)しか持たない。

### 5.33.2 階層の深化:登録の下に登録可能性がある

従来の暗黙の階層:登録 → ネットワーク → 次元。しかし一段深い階層がある:

> **登録可能性 → 登録 → 流れ → 持続 → ネットワーク → 次元**

### 5.33.4 与えてよいものの最終候補と、測度の警告(揺さぶり)

**最終候補:一様な登録可能性、一つのみ。** これは公理「差がある」を様相込みで読んだものと同一であり、公理は増えない。

**警告(自己監査):**「登録可能性」を初期条件として許すことは、本当に何も与えていないことになるか。可能性の場にも「どこで・どれだけ」という構造(**測度**)が要り、その測度を一様と置くことは背景の再密輸(容器候補のさらに奥)になりうる。逃げ道は一つ:**可能性の測度自体が過去の登録から生成される**(登録が次の登録可能性を変形する —「差が差を生む」の様相版)なら循環せず閉じる。ただし最初の一歩(無からの第一登録)の確率構造だけは、公理と同格の「原初の対称性」として置くほかない可能性がある — ここは確定させず、開いたまま記録する。

「ノード時計 → リンク登録の分配則」という問いは、この枠では **登録可能性がネットワーク上でどう分布するかの規則そのもの**である。二つの問いは一つに統合される:

## 5.34. 登録可能性保存則と臨界性の導出(紙上検討の記録)

記載日:2026-07-07。§5.33.5 の紙仕事の記録。

### 5.34.1 前提二つ(名前つき)

- **前提 1(K1、確立済み):** 登録は離散。1 イベント= 分割不能な 1 個の差。
- **前提 2(登録可能性保存則、新規・要監査):** 登録された差は、**それ自身がちょうど 1 個の新しい登録可能な差である。** log が 1 目盛増えたこと自体が 1 個の差(前/後の区別)であり、それ以外に登録可能性の源はない(公理:差しかないなら、差の根拠になれるのも登録された差だけ)。

### 5.34.2 分岐比 1 の導出(恒等式として)

1 回の登録は可能性を 1 単位消費し(可能だった差が現実の差=過去になる)、1 単位生産する(登録それ自体が新しい差)。σ = 1/1 = 1。**1 回の登録が 2 個の差を産むなら、それは 2 回の登録だったはず** — K1「登録に中間はない」の裏面「登録に倍数もない」。量子の勘定が臨界性を強制する。

> **総量= 1(前提 2)が安定性(σ = 1、臨界)を決め、分配の形(等分/C 重み/勾配比)は幾何のみを決める。**

γ は登録可能性を消す(忘却)。前提 2 のみなら σ = 1 だが、減衰込みの実効は σ_eff < 1 で放置すれば消滅。これを補うのが**原初の一様床=揺らぎ**(§5.33.2:hbar_eff =登録可能性の強度)。

床からの第一イベントは、既存構造がなければ**自ら登録する二極を作る**(差は二極を要するため、第一登録=最初のダイアド生成)。種は「与えられるもの」から「第一量子の産物」に変わる — §5.33.3 の容器候補が除去可能になる。

## 5.41. v18 の設計固定(実施前登録):台帳の有向化 — 反対称セクターの復元

### 5.41.1 理論的動機:静かな脱落の発見

v5 以降、H・C・台帳をすべて**対称**に組んできた。だが VED の C_ij は向き付き(C_ij ≠ C_ji)であり、反対称部 A_ij こそ時間・循環のセクター(K8)、Phase 4「field strength is memory in circulation」の住処である。渦=循環には方向が要る。**方向を消したモデルに渦が立たないのは当然だった** — 対称化は容器(不当な付与)の逆:**与えるべき構造の不当な削除**。§5.40.5 の問い「冷たいまま活動を維持する循環」への答えの候補は、失われた反対称セクターの復元にある。

### 5.41.2 モデル定義(v17-C からの変更点)

1. **台帳の有向化:** w_ij ≠ w_ji。イベントは向きを持つ(i→j)。
2. **継続分配則(パラメタフリー):** イベント i→j の預け入れ総量 1 は、**j から出る有向リンク(j→k, k≠i)へ**分配される — 流れは続く。j の出口が (j→i) のみなら反射。**発火したリンク自身には預けない** — 自分を維持するには上流から再給餌される必要がある=**持続には循環が要る**、が構造として入る。分配形は C 重み(§5.38 の C 変種を継承、有向版)。
3. 遅い層(H, C)は対称のまま(最小変更)。渦は構造ではなく**登録可能性の持続的循環**として速い層に住む —「memory in circulation」の忠実な実装。
4. σ = 1 は総量 1 の不変性により保持 — 台帳監査で直接検証。

### 5.41.3 仮説と測定

- **H3:** 有向継続分配は台帳渦(サイクル上の循環)を可能にし、計量窓の**占有率と持続長**を対照(v17-C、対称分配)より有意に上げる。

### 5.41.4 失敗モード(事前固定)

- **(i) 占有率不変:** 方向性だけでは不足 — 渦は速い層でなく構造(遅い層のサイクル、K6 本体)に要る、という診断へ。
- **(ii) 不安定化の再来:** 有向化が σ = 1 を破っている(監査で検出)か、継続則が暴走路 — 勘定の見直しへ。

## 5.47. 代謝振動の二変数モデル(紙上検討の記録)

## 5.54. 自己訂正と再枠組み:2.6 は「終着値」ではなく「非整数の基盤次元」

記載日:2026-07-08。§5.53 の判定の含意を訂正し、問いを正しい階層に置き直す。

### 5.54.1 v23 判定の穴(自己訂正)

§5.53.4 で「d(N) 平坦 → 2.6 が真値」と書いたが、平坦だったのは**窓内の瞬間実効次元**であって、窓の伸び方の共スケーリングではない。2 点(N=300, 450)で瞬間 d を見ただけでは、2.6 が「裸の基盤次元(終着値)」なのか「**まだ伸びている途中の窓の固有値**」なのかを原理的に分離できない。

**訂正:** §5.53.4 の「H10 棄却(= 3 でない)」は「**観測範囲で 3 でない**」までは正しい。しかし「2.6 が終着値」への含意は先走りだった。正しくは:**長寿命窓の固有実効次元は観測範囲で非整数 ≈ 2.6 であり、それが基盤の終着値か粗視化前段かは未判定。**

### 5.54.2 見るべきは瞬間 d ではなくスケーリング

測るべき量は、次元そのものより先に、**窓幅・安定時間・相関長・実効次元が、N・登録イベント数・履歴深度に対してどう伸びるか**である。三分岐が判定できる:

- **裸の基盤次元:** 登録量 ↑ → 窓は長くなるが d → 2.6 固定、相関長は窓幅に比例(自己相似)。
- **3 への粗視化前段:** 登録量 ↑ → 粗視化スケール依存の d(ℓ) がゆっくり上昇、相関長がシステムサイズより速く伸びる。
- **基盤→観測の二段構造:** d_local → 2.6 固定+その上に整数化層(粗視化ブロックの d_block が 3)。

これらは瞬間 d では区別できず、**粗視化スケール依存の d(ℓ)** と、窓四量が登録深度に対して描くスケーリング指数で分かれる。

### 5.54.3 主張の置き方(採用)

> **現時点で得られたのは 3 次元の導出ではなく、背景なし登録ダイナミクスにおいて、長寿命の計量窓が固有の非整数実効次元(≈ 2.6)を持つという結果である。観測 3 次元との関係は、直接同一視ではなく、粗視化・整数化・観測選択の問題として扱う。**

これは §5.53 の「3 は棄却」より強く、かつ安全である:「3 でない」でも「2.6 が終わり」でもなく、「**非整数の基盤次元が実在し(H9)、観測次元との関係は未解決の粗視化問題**」。反証志向を保ったまま、問いを正しい階層(基盤次元 vs 観測次元)に置き直している。「3 に直行するモデルは、どこかで 3 っぽさを密輸する危険が高い」— 段階構造(登録 → 窓 → 伸長 → 準安定化 → 粗視化で整数読み)を経由するのが自然であり、その各段を測る。

### 5.54.4 v23 判定後の再整理:安定窓は伸びなければならない

v23 の独立追試により、長安定窓の固有次元は約 2.6 に収束し、「3」は現時点では支持されなかった。これは H9(準定常な固有次元の実在)を否定するものではなく、「3 を直接導出する」という読みを退ける結果である。

この判定を踏まえ、ルート II の目的を次のように整理し直す。

**観測 3 次元を直接得ることではなく、差分登録の成長とともに計量窓そのものがどのように成熟するかを測る。** 安定窓は、固定された一つの相ではなく、登録深度とともに伸長しうる構造である可能性がある。

したがって、現時点で測定された約 2.6 は、
- 裸の登録基盤の固有次元、
- 3 次元への粗視化前段、
- あるいは二段構造の第一層、

のいずれにも属し得る。この段階で「最終的に 3 へ到達する」と主張することは、観測結果より先に結論を置くことになるため採らない。

むしろ重要なのは、**登録深度・履歴長・粗視化スケール・計量窓の持続時間**が共にどのようなスケーリング則を持つかである。

次のキャンペーン(v24)では、瞬間的な d の値ではなく、**d(ℓ, N)・窓幅・安定時間・相関長の共スケーリング**を主要観測量とし、

1. 基盤次元で飽和するのか、
2. 3 へ漸近するのか、
3. 基盤次元と観測次元の二段構造を示すのか、

を判定対象とする。

この再整理により、本研究は「**3 を探す実験**」から「**計量窓の成熟過程を測る実験**」へと位置付けを更新する。

**監査状態:** 本項は §5.54.1–5.54.3 を受けたルート II の目的の公式再定義。v24 の判定対象(三分岐)を確定する。

## 5.55. 現段階の到達点:次元は「読めるようになった履歴」である

記載日:2026-07-08。v1–v23 と紙上検討の全系列を踏まえた、ルート II の現段階の総括。**これは結論ではなく到達点であり、末尾に射程の留保を付す。**

### 5.55.1 次元は「法則」ではなく「読めるようになった履歴」

最初の問い「なぜ空間は 3 次元か」は、実験を通して「**どのような差分登録の履歴が、計量として読める独立方向を持つのか**」へ変わった。次元は世界の背景設定ではなく、登録された差分構造の中から観測・再利用・粗視化に耐える方向数として読まれる。ノート冒頭「次元は存在論ではなく、差分構造の有効記述である」と、失敗ログの全系列が一致した。

### 5.55.2 次元は常にあるのではなく「窓」として現れる

構造があればいつでも次元が測れるわけではなかった。多くは無次元・small-world 崩壊・core-periphery 化・飽和・断片化に落ちた(§5.7–5.13, 5.27–5.28)。意味のある対象になったのは計量窓だけ。次元は構造全体の恒常属性ではなく、**登録・忘却・閉包・流れのバランスが準定常的に揃った領域にだけ立つ相指標**に近い。

### 5.55.3 「3」は直行しなかった — それが健全だった

v22 で長窓内 2.79 ± 0.12(H9 の強い事例)。v23 独立追試で 2.5–2.7 に寄り、3 とは分離される方向、「3」は棄却、ただし H9(準定常次元の実在)は維持(§5.53)。**もし無理に「3 が出た」と読んでいたら、VED が最も避けてきた密輸に近づいていた。** 実際には「3 ではなかった、しかし固有次元を持つ準定常窓はあった」— 3 次元導出より一段基底の発見。

### 5.55.4 2.6 は終着値とは限らない

平坦に見えたのは窓内の瞬間実効次元であり、窓幅・安定時間・相関長・粗視化スケールの共スケーリングは未測定(§5.54)。2.6 が裸の基盤次元か、3 へ向かう途中の窓の固有値かは未判定。三分岐(基盤で飽和/3 へ漸近/二段構造)のいずれとも今は決めないのが正しい。

### 5.55.5 次元とは「持続した差分の再利用可能性」でもある

差分がただ存在するだけでは次元ではない。**登録され、持続し、他の構造から再利用可能になり、測定可能な窓を形成したとき**に初めて方向数として読める。この意味で関係的次元・状態的次元・情報次元はバラバラでなく、差分がどの棚で独立性を保つかの違い(§1.5–1.6、情報次元は第三の棚でなく両者を跨ぐ操作)。

### 5.55.6 現段階での最も安全な要約

> **次元とは、差分登録の履歴が、一定の代謝条件のもとで計量窓を形成し、その窓の中で独立方向として再利用可能になったときに現れる有効ランクである。観測 3 次元は、現時点では直接導出されたものではなく、この計量窓の成熟・粗視化・整数化・観測選択の先に置かれる未解決問題である。**

### 5.55.7 射程の留保(この総括をどこまで信じてよいか)

§5.55.1–5.55.6 の言葉の強さは、証拠の幅を先取りしている箇所がある。証拠は限られた観測(seed 数本、NMAX 300–450、**単一の転化則=細分のみ**)から引かれている。特に:

- **d ≈ 2.6 が「VED の基盤次元」か「細分則という一実装の癖」かは未分離**(§5.53.6 の予約)。純粋細分は DM 級 d=∞ を作り、死+保存則で有限化して 2–3 間に落ちる — この 2.6 が転化則の関数である可能性を、別の新ノード生成則で再測定するまで排除できない。現段階の総括は「**細分モデル族における**次元現象の記述」に留まる可能性がある。
- 「計量窓=相指標」「次元=再利用可能性」という枠自体も、この一族の観測からの一般化であり、他の転化則で相構造が変われば修正されうる。

したがって §5.55.6 の要約は、**現時点で最も安全な言い方**であると同時に、**転化則非依存性が確認されるまでは暫定**である。次の二つ(v24 スケーリングキャンペーン/転化則の変更による再測定)が、この総括を確定させるか修正するかを決める。

**監査状態:** §5.55.1–5.55.6 は到達点の総括。§5.55.7 は射程の留保(総括を細分モデル族に限定する可能性の明示)。全体として **open** — 確定には転化則非依存性の確認が必要。

## 5.56. v24 の設計固定(実施前登録):窓の成熟スケーリング × 転化則非依存性

細分は「差が二極を要する」(第一登録=ダイアド、§5.34.5)の反復である — **新しい差は既存の差の間に入る**。出芽(端から生える)も面貼り(既存を繋ぐ)も、この「間に入る」を満たさない。したがって:

> 計量窓が細分を要求することは、恣意的な実装依存ではなく、**「差は既存の差の間に登録される」という公理的様式の帰結**である可能性がある。細分族への限定は、総括の弱化であると同時に、**「なぜ細分か」を公理に接続する**新しい問いを開く。

## 5.58. 積層仮説と観測 3 次元の切り分け(紙上検討の記録)

記載日:2026-07-08。§5.57 の「窓は細分を要求する」を受けた、3 への道筋の仮説化 — ただし**観測 3 次元との関係を厳密に切り分ける**。

### 5.58.1 三命題の分離(混ぜると密輸)

- **(A) 観測事実:** 我々が経験する空間方向は 3 である。動かない与件、無視しない。
- **(B) モデルの現状:** 細分層は非整数(2.6–3.x、未確定)の計量窓を出す。積層仮説はまだ絵。
- **(C) 接続の主張:** モデルの何かが (A) の 3 を説明する。**未証明、証明の負荷はモデル側にある。**

**非対称の明記:** (A) は (C) の**目標**であって**証拠**ではない。観測の 3 は、モデルが 3 を出す理由にはならない。モデルが非整数で止まっても観測の 3 は消えない(モデルが不完全なだけ)。したがって観測 3 は「モデルが最終的に接続を負う相手」として据えるが、「モデルの中間結果を 3 へ引っ張る重力」としては**使わない**。この非対称が本節の背骨。

### 5.58.2 積層仮説

> **3 次元は基盤層の値ではなく、細分された差分構造が飽和して溢れ、複数レイヤーに重なったときの観測有効次元である。**

機構の絵:差分が細分される → 登録が飽和する → 溢れが生じる → 新しい層に逃げる → 層が重なり、観測上は 3 として読める構造へ近づく。VED 的整合:「差を閉じたらダメ」なので単層は 2.6 で持続する(非閉包帯)。「差が溢れる」ので層が増える。その層構造が観測に届くと 3 として読まれる。

### 5.58.3 §0 監査への服従:名指しすべき署名三つ

本仮説は「protection/cancellation を主張するなら残余の行き先の層を名指しし、そこに独立に測定可能な署名を与えよ」(§0)に服する。三署名:

1. **溢れの署名:** 飽和ノード(C→C_max)で新登録が同一層内でなく別位相へ流れる。§5.28(新生リンクは生まれた瞬間から熱い)+ §5.13.4(計量は非閉包帯にのみ)を重ねると、飽和層は計量を持てず外側の非閉包帯だけが窓になる。**溢れ=飽和層から非閉包帯への差分の押し出し** — 部分的に既観測。
2. **層の署名:** 単一窓の d(ℓ) が**二プラトー**を持つ(§5.56.3 の二段構造判定)。小 ℓ で細分層の 2.6、大 ℓ で積層の高い値。v25 で直接測定可能。
3. **積層のランク加算:** 層数 k と観測次元の関係。2.6 の層が k 枚で単純に 3 になるわけではない(2.6×2 ≠ 3)。**どういう重なり方が 2.6 を 3 にするかの算術**が要る — ここが最も危うい。

### 5.58.4 危険点の名指し

最も魅せられやすいのは (C) の 3 の部分。「溢れて層になって 3」は物語として完結しすぎている。現データが言えるのは**溢れの存在(飽和と非閉包帯の共存)**までで、「層が 3 を作る」は完全に未測定。§5.53 で d=3 を棄却したのと同じ厳しさを積層仮説にも向ける:**積層して 3 になることを、3 を仮定せずに測れるか。** d(ℓ) の二プラトーが出て、大 ℓ プラトーが 2.72(e)や 2.6 の倍数でなく 3 に、しかも他候補を排除して寄る、が確認されるまでは、これは「3 へ向かう道筋の候補」であって「3 の導出」ではない。

**監査状態:** §5.58.1 は三命題の分離(規律)。§5.58.2 は仮説。§5.58.3 は署名(1 は部分観測、2・3 は未測定)。§5.58.4 は危険点。全体 **open** — v25(署名 2 の測定)が第一検定。

## 5.59. v25 の設計固定(実施前登録):d(ℓ) 二プラトー探索 — 積層仮説の第一検定

記載日:2026-07-08。**本節は実施前に固定された設計であり、実行後に遡って変更しない。** 核:**一つの窓スナップショット内で粗視化スケール ℓ を動かし、次元がどう変わるか**を測る。二プラトー → 積層、単一プラトー → 単層。

### 5.59.1 測定量の定義(心臓、事前厳密化)

窓スナップショットの測地距離行列 D から、**ball 次元の局所スロープ** d(ℓ) = d log N(r) / d log r を r=ℓ で評価。ℓ を最近傍間隔から窓径まで掃引。実装:log N(r) vs log r 曲線に ℓ 中心の移動窓で局所線形フィット。**単一代表値に潰さず、d(ℓ) 曲線そのものを出力。**

### 5.59.2 署名の事前定義(§5.58.3-2 の判定基準)

- **単層:** d(ℓ) が一つのプラトー(平坦帯)。
- **二段(積層):** d(ℓ) が 小 ℓ プラトー → 遷移 → 大 ℓ プラトーの階段。小 ℓ = 層内次元、大 ℓ = 積層次元。
- **粗視化前段:** d(ℓ) が単調上昇で飽和なし(プラトーを作らない)。

### 5.59.3 較正(計器自身の脚を確認)

既知の二層構造(2 次元格子を 3 次元に薄く積んだスラブ、既知 d_local=2 / d_block=3)で d(ℓ) を測り、**二プラトーが計器で検出できることを先に確認**。検出できなければ「二プラトーなし」は計器の限界であって物理の否定ではない — この切り分けを走行前に固定。単層対照(純 2 次元格子=単一プラトー)も。

### 5.59.4 軸

- **T1 細分のみ**(§5.57 で窓を出すのはこれだけと確定)。
- **N ∈ {300, 450, 650}** — 積層仮説は「深いほど層が増える」を予言するため、大 ℓ プラトーが N とともに上昇するかが第二署名。
- 長窓(H9 成立、≥ 5 点)のスナップショットのみ対象、seed 12 本から収集。

### 5.59.5 判定(事前固定)

- **二プラトー検出 ∧ 大 ℓ プラトーが N で上昇** → 積層仮説支持、署名 2 成立 → 次は署名 3(ランク加算の算術)。
- **単一プラトーのみ** → 積層棄却。2.6(or 3.x)は単層の固有値、観測 3 への道は別機構。
- **プラトーなし単調上昇** → 粗視化前段、d(ℓ→大)の外挿値が次の主張対象。
- **どの場合も「3」条項継続:** 大 ℓ プラトー/外挿値が 3 でも、他候補(e, 2.6 倍数, π)排除まで主張しない(§5.58.1 の非対称:観測 3 は目標であり証拠でない)。

### 5.59.6 妥当性・失敗モード

**妥当性:** 較正で二プラトー検出能を確認済み/長窓 ≥ 3 本/d(ℓ) 曲線が測定成立(スロープ推定の誤差帯が判定に足る)。

**失敗モード:**
- 窓が小さすぎて ℓ のダイナミックレンジ不足(プラトー判定不能)→ N 増で窓径を稼ぐ、一度だけ。
- d(ℓ) が seed 間で不一致 → 窓ごとに層構造が違う=積層は普遍でない、として記録。

**監査状態:** 設計の事前登録。実行結果は次節以降に記録し、本節は変更しない。
