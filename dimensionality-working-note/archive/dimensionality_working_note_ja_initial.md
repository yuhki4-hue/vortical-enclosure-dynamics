## 1. 問いの転換:次元は容器ではなく観測されたランク

物理は 3+1 次元を観測する。VED の公理は「差がある」のみであり、次元数はどこにも仮定されていない。したがって次元はもともと **フリー** である。

問いはこう転換される:

> なぜ次元は 3+1 か → **なぜ自由度の伸長が 3(+1)で観測されるのか**

次元は差分が伸びた方向の観測されたランクであり、伸長自体は任意ランクに起こりうる。観測されるのは **持続した** 構造だけである。ゆえに「観測次元」とは「差分構造が持続可能なランク」の別名になる。

**監査状態:** 問いの再定式化。主張ではない。

## 1.5. 次元の二つの型:関係的次元と状態的次元

一般の科学言説(物理・数学の運用レベル)では、「次元」という語が二種類の異なる概念を無自覚に往復している。VEDの語彙で明示的に分離しておく。

**関係的次元(ユークリッド型/extensive/底空間型)**
ノード**間**の距離構造(d_ij = −log S_ij)を等長に実現するのに要する独立方向の数。外側的・関係的。ファイバー束の言葉で言えば **底空間** の次元にあたる。§4〜§5(K5〜K7)で扱う「渦が持続できる独立方向の数」は完全にこちら側であり、動力学的な選別(絡みの位相保護)によって決まる。

**状態的次元(ヒルベルト型/intensive/ファイバー型)**
一つのノード**が**内部に保持する状態の自由度の数。関係の話ではなく、単一の点が「何を保持できるか」の話。ファイバー束の言葉で言えば **ファイバー** の次元。ゲージ内部空間、状態ベクトルの成分数などがこちらに属する。

**一般の混同のされ方**
場の理論では本来この二つは厳密に分離される概念だが(底空間 vs ファイバー)、余剰次元と内部対称性の次元が同列に語られたり、ヒルベルト空間の次元と空間的次元が地続きに扱われたりする場面は運用上多い。区別する語彙はあるのに、しばしば溶ける。

**次元の一般定義(暫定・本ノートの立場)**
> 次元とは、登録された差分のうち、代数的制約または動力学的持続条件によって独立な区別として生き残った方向の数である。この定義は関係的次元・状態的次元のどちらにも中立に適用されるが、**両者は異なる棚に属する量であり、数値が一致しても直ちに同一視してはならない**。

以下の残差の棚卸し(§2)は、この区別が徹底されていなかった箇所の記録でもある。

> e_i は埋め込み空間(底空間)の接ベクトルなのか、それとも埋め込みと無関係な独立の内部(ファイバー)空間のベクトルなのか

## 3. 中核提案:登録の離散性(公理の系として)

### 3.1 導出

運動が幾何として構成可能であるためには、関係の項になる **完了した登録** が必要である。登録が連続——あらゆる登録が永遠に「途中」——なら、関係の項が存在せず、幾何は立たない。運動は幾何になれず未分化の流れに留まる。

これは公理から次の形で従う:

> 「差がある」とは区別が成立していることである。区別に程度はない——半分だけ区別されたものは、まだ区別されていない。登録とは区別の成立であり、成立に中間はない。**ゆえに登録は離散である。**

これは独立の公理ではない。公理「差がある」を登録の側から読んだ **系(corollary)** である。公理は一つのまま。

### 3.2 直ちに従う再解釈

- **H は登録イベントの列**になる。連続的な H(t) は、イベントレートが速い極限の粗視化記述に格下げされる(既存の連続式は全て有効記述として無傷で残る)。
- **背景時間 t が不要になる**(§2.3 の残差の解消)。根源的なのはイベントの順序と数のみ。dτ/dt = ρ は「登録イベント 1 回につき τ が 1 目盛進む」の連続極限として導出される式になる。
- **χ = λρH に最小増分**が入る。累積露出 χ は離散通貨で支払われる。
- **ツェノン問題の解消**(副産物):運動は連続空間の通過ではなく登録の更新列であり、無限分割が生じない。

### 3.3 hbar との合流(狙わずに閉じた接続)

stochastic-quantization で `hbar_eff = a² S_Δ`(差分場の揺らぎ強度)は導出済み。登録が離散なら、hbar は **登録一回分の最小通貨** という解釈を自然に得る。「なぜ作用に量子があるか」への VED の答えが「登録に中間がないから」になる。この接続は本ノートの導出過程で設計されたものではなく、離散登録を入れた時点で自動的に閉じた。

**監査状態:** §3.1 は系としての導出(紙上)。§3.2 は §3.1 からの直接の帰結。§3.3 は解釈の合流であり、独立の検証(hbar_eff の最小増分がイベント単位と一致するかの数値確認)が未実施 — **open**。

## 5. グラフ内在的絡み数:定義の候補と淘汰の記録

型 1(安定性選択:任意ランクに伸び得るが持続するのは 3 のみ)を検証可能にするには、埋め込み座標なしの絡み数が要る。判定基準:(a) C, ρ, H / χ, a のみで書ける、(b) 再アドレス不変、(c) 離散的に絡みを区別し log の局所更新で保存。

**候補 A(相互循環 / 離散 Biot–Savart):** γ₂ が誘導する反対称 exposure を γ₁ で周回積分。ゲージ不変だが、伝播則が D(transport)に依存し、絡みの定義に先立ってランク情報が混入する。**保留(半歩井戸)**。

**候補 B(組合せ交差符号):** ノードでのリンク巡回順序から交差符号を定義。巡回順序 = 局所平面性 = 次元の密輸。**却下**。

**候補 C(再アドレス障害 → 緩和障害へ修正):**
- 初版:「φ を動かして F_p² を最小化、残差を絡みとする」— **紙上で欠陥発見**:F_p はループ和ゆえ再アドレス不変であり、φ の探索は空回りする。定義として死んでいる。
- 修正版:緩和をゲージ軌道上の探索ではなく **τ に沿う Langevin 緩和(閉包動力学そのもの)** に差し替える。γ₂ の χ を凍結拘束し、系を流し、全系 F² 総和が落ちきるかを見る。**絡み = 動力学が到達できない残差床**。
- 副産物:「ループの内部」(Jordan 曲線問題)が定義から消える。床は全系で測ればよく、定義は γ₁↔γ₂ 対称になる。
- VED 的意味:絡みとは「互いの log が互いの完全緩和を禁止する度合い」— 非閉包原理の直訳であり、Phase 4 の測定事実「ゲージ軌道は決して平衡しない」と直結する。

**採用:候補 C 修正版。** ただし K4(コンパクト化)が前提。非コンパクト ℝ では床が常にゼロへ漸近することを紙上で確認済み — これが K4→K5 の必要性の発見経路である。

**監査状態:** 候補 C 修正版は定義として成立(紙上)。数値プロトタイプ未実施 — **open**。
