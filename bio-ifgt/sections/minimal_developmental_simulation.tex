\section{Minimal Developmental Simulation (Bio-IFGT Toy Model)}

\subsection{Purpose}

This section introduces a minimal Bio-IFGT toy model. The purpose is to illustrate how a small set of DNA-like parameters, including sources, diffusion, decay, thresholds, and response rates, can generate reproducible finite-horizon model patterns without encoding a completed output array. The prescribed source and positional window do, however, supply coarse spatial information.

\subsection{Model Setup}

We consider a two-dimensional domain representing an embryo-like field. The system evolves over discrete time steps and consists of four primary fields:
\begin{itemize}
  \item morphogen-like model field \(M(x,y,t)\),
  \item model information density \(\I(x,y,t)\),
  \item neural-like commitment \(N(x,y,t)\),
  \item eye-like commitment \(E(x,y,t)\).
\end{itemize}

An auxiliary boundary field is also introduced:
\begin{itemize}
  \item gradient-sensitive boundary-like accumulation \(B(x,y,t)\).
\end{itemize}
These symbols are source-local toy fields and become finite arrays in the executable implementation. The toy \(\I\) is a finite proxy for the Bio-IFGT field, not a carrier identity with it, and the code does not directly integrate independent \(\J\) or \(\PhiI\) arrays. The discrete loop step and its \texttt{DT} are runtime quantities, not the Bio internal variable \(\tau\) or a biological clock.

\subsection{Dynamics}

\paragraph{Morphogen field.}
The morphogen field evolves by diffusion, decay, and localized production:
\begin{equation}
  \frac{\partial M}{\partial t}
  =
  D_M \nabla^2 M - \lambda_M M + \sigma_M(x,y).
\end{equation}

\paragraph{Information density.}
The information density accumulates from the morphogen field while also diffusing and decaying:
\begin{equation}
  \frac{\partial \I}{\partial t}
  =
  D_I \nabla^2 \I - \lambda_I \I + \alpha M.
\end{equation}

\paragraph{Neural commitment.}
Neural commitment is updated by thresholding the information density:
\begin{equation}
  N_{t+1}
  =
  N_t + \eta_N S(\I - \theta_N)(1 - N_t).
\end{equation}

\paragraph{Boundary field.}
The boundary field is derived from the gradient structure of information density:
\begin{equation}
  G = |\nabla \I|.
\end{equation}
This displayed \(G\) is the paper's raw gradient magnitude. The current code normalizes that magnitude globally before using it as the input to the \(B\) update; the normalized input and the accumulated state \(B\) are distinct from raw \(G\). The nucleotide symbol \(G\) used in the DNA alphabet is also unrelated.
The paper uses the boundary-field label for regions selected by strong local spatial variation. The code's (B) is an accumulated state rather than an instantaneous boundary detector. At the reported horizon it highlights boundary-like bands, while longer audit runs show the thresholded mask spreading across the grid; it should not be read as a permanent stable biological boundary.
It is updated through the following thresholded rule:
\begin{equation}
  B_{t+1}
  =
  B_t + \eta_B S(G - \theta_B)(1 - B_t).
\end{equation}

\paragraph{Eye-like commitment.}
The eye-like commitment field is updated only where neural commitment, boundary stabilization, and a positional window are simultaneously active:
\begin{equation}
  E_{t+1}
  =
  E_t
  + \eta_E S(N - \theta_{EN}) S(B - \theta_{EB}) A(x,y)(1 - E_t).
\end{equation}
The thresholding function is
\begin{equation}
  S(z) = \frac{1}{1 + e^{-kz}}.
\end{equation}
This \(S\) is a symbolic threshold family in the paper. The execution source implements separate general and eye-specific sigmoid functions with steepness constants \(8\) and \(20\), respectively, and clips their exponential arguments; these implementations are not one identical function instance.

\paragraph{Paper form and finite execution.}
The displayed \(M\) and \(\I\) relations are continuous model forms, while the current code represents them by explicit finite updates with a prescribed source profile. Within each loop, the code first updates \(M\), then updates \(\I\) using that newly updated \(M\). It next updates and clips \(N\), computes the globally normalized gradient input from the updated \(\I\), updates and clips \(B\), and finally updates and clips \(E\) using the current \(N\) and \(B\), the explicit positional window, and the eye-specific sigmoid. The code applies \texttt{DT} to the \(M\) and \(\I\) updates but not to the source-specific \(N\), \(B\), or \(E\) accumulation rules. This ordering is an execution property, not a new equation or a simultaneous-update claim.

\subsection{Interpretation}

The model does not encode a completed neural- or eye-like output array. It does specify localized sources \(\sigma_M\), diffusion and decay parameters, threshold conditions, response rates, and an explicit positional window for \(E\). Under those supplied constraints, a hierarchical model pattern appears:
\begin{enumerate}
  \item a smooth morphogen gradient forms in \(M\),
  \item an information-density landscape develops in \(\I\),
  \item a neural-plate-like model region appears through thresholding in \(N\),
  \item a boundary-like accumulated pattern is selected from gradient-sensitive input in \(B\),
  \item an eye-like localized model pattern appears through secondary thresholding and the positional window in \(E\).
\end{enumerate}

\subsection{Key Observation}

The emergence proceeds through successive constraints:
\begin{equation}
  M \rightarrow \I \rightarrow N \rightarrow B \rightarrow E.
\end{equation}
This compact sequence is a staged navigation summary, not the exact dependency graph of the executable update. In the current code, the prescribed source updates \(M\); the newly updated \(M\) feeds \(\I\); \(\I\) feeds \(N\) and separately supplies the raw gradient that is normalized before updating \(B\); and the updated \(N\) and \(B\), together with the positional window, feed \(E\). In particular, \(N\) is not a direct input to the \(B\) update, so its position before \(B\) records staging rather than an \(N\)-to-\(B\) causal edge.
Each stage introduces a higher-order structural condition:
\begin{itemize}
  \item \(\I\): scalar field,
  \item \(\nabla \I\): first-order structure,
  \item thresholding: discretization,
  \item combined conditions: localization.
\end{itemize}

\subsection{Conceptual Implication}

The simulation illustrates that the completed model pattern need not be encoded as an input array. At the reported finite horizon it appears reproducibly within a constrained landscape that includes prescribed source geometry and an explicit positional window; this is not geometry-free emergence, a stationary solution, or an asymptotically stable solution claim.

In this sense, DNA-like parameters act as conditions that shape the geometry of possible states.

\subsection{Relation to Bio-IFGT}

Within the Bio-IFGT framework:
\begin{itemize}
  \item \(\I\) serves as the toy proxy for Bio-IFGT information density,
  \item \(\PhiI \sim -\I\) defines an effective potential landscape,
  \item \(\J \sim -\nabla \PhiI\) induces flows toward stable regions.
\end{itemize}
These \(\PhiI\) and \(\J\) statements are formal or interpretive correspondences; the finite code does not implement a literal one-to-one mapping to independently integrated \(\PhiI\) or \(\J\) arrays. None of the toy fields is operationally mapped here to a measured biological observable.
The reported finite-horizon structures admit an attractor-like interpretation. The toy run does not establish a formal basin, invariant region, asymptotic convergence, or membership in \(\Omega_{\mathrm{life}}\).

Each stage in the generation path \(M \rightarrow \I \rightarrow N \rightarrow B \rightarrow E\), read as the staged navigation summary above, can be interpreted as a successive localization of quasi-closure: the morphogen field establishes a global information gradient, which drives local accumulation of \(\I\), which in turn crosses thresholds that label persistent sub-regions at the reported horizon. The eye-like commitment \(E\) represents a secondary quasi-closure, supported by but distinct from the neural-plate-like region \(N\). This interpretation does not replace the distinct execution dependencies or supply a formal quasi-closure map. The hierarchical structure mirrors the attractor-within-attractor interpretation of differentiation developed in Section 7.7.

\subsection{Limitations}

This model is intentionally minimal and does not attempt to reproduce biological detail. It provides a finite model-local witness of organization and qualitative structural analogy under constrained dynamics. Longer audit runs continue to evolve, and the limited relaxation and recommitment observed under selected perturbations do not establish general return, biological robustness, or regeneration. No external biological dataset, calibration, or operational model-to-observable map is used here.
