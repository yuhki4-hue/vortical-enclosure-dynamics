# Bio-IFGT

Bio-IFGT: Biological Morphogenesis as Information-Flow Attractor Dynamics is a LaTeX paper for the biological coarse-graining of IFGT/VED.

The project frames biological development as a problem of biological constraint-density \(\I\), information flow \(\J\), induced potential \(\PhiI\), and attractor stability. DNA is treated as a parameter set or operator-only medium, while morphogenesis is described as convergence toward stable attractor configurations. Life is formulated as a dynamically sustained non-equilibrium state.

This repository is related to the note essay as a formalization layer. The note may motivate the conceptual background, but this paper keeps the technical language centered on non-closure, flow, stability, sustained dynamics, and effective attraction or gradient-driven bias. Intelligence appears only near the end as a second attractor built upon life.

## Structure

- `main.tex`: Main LaTeX entry point.
- `main_ja.tex`: Japanese LaTeX entry point.
- `sections/`: Section files in paper order.
- `sections_ja/`: Japanese working sections.
- `refs.bib`: Bibliography file.
- `simulations/minimal_neural_field/outputs/`: Figure assets used by the toy-model section.
- `notes/handoff.md`: Design rules and terminology constraints.
