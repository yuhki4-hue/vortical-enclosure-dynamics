## Fig.1 — The C-Landscape and the Inference Trajectory

（C-地景と推論軌道）

### (i) 一文要約

推論は閉包度の地形(C-landscape)の上を勾配 ∇C に沿って動き続けるが、構造的にどこにも止まれない——これが非閉包定理(定理 3.1)の幾何学的表現である。

### (ii) 要素の読み方

- **横軸 𝒳・縦軸 C**: 横軸は状態空間(あらゆる推論状態の並び)、縦軸は閉包度 C(その状態がどれだけ安定して停止可能か)。
- **黒い地形曲線(C-landscape)**: 概念空間の地形。山(高 C)は安定しやすい領域、谷(低 C・高 ∇C)は未決定で推論の駆動力が大きい領域、鞍点は分岐の起点。地形が一様でないのは、安定しやすい場所としにくい場所があることを表す。
- **緑の点(local max)**: 局所極大。「ここなら一時的に止まれそう」に見える地点。
- **赤い破線(上端 C_max)**: 完全閉包の境界。VED 基本式の項 −κ_B/(C_max − C) が C→C_max で発散するため、地形はこの線に近づくほど急峻になり、到達できない。右端の赤いグラデーションが発散領域。
- **青い軌道(x₀ → xₙ → xₙ₊ₖ)**: 推論演算子 F の反復が描く軌跡。地形を登り続けるが、緑の局所極大を**通過しても静止しない**(紫の注記「passes through, does not settle」)。

### (iii) 理論的含意

右上のカードが定理 3.1 の証明である。仮に停止点 x*(F(x*)=x*)があれば、正当化の単調性(前提 P2)により J(F(x*)) > J(x*)。だが不動点ゆえ F(x*)=x* なので J(x*) > J(x*) となり矛盾。ゆえに内部不動点は存在しない。

下部の式 `∀x: F(x) ≠ x` の限定「within fixed θ, movement-type A」が重要である。これは運動可能領域 Ω_θ を固定したまま内部を動く(A)範囲での主張であり、§5 で μ_θ が領域そのものを組み替える(B)と、別の形で停止(L_E)が創発する。本図は「推論層 L_F は単独で閉じない」という第一中心(§3)を示し、その停止が後に外部依存的に供給されること(§5、第二中心)への伏線となる。「推論は動くように設計されている、止まるようには設計されていない」——非閉包は欠陥ではなく運動の構造である。

## Fig.2 — Responsive and Silent Regimes as Threshold Phenomena

（応答的世界と沈黙的世界——閾値現象としての二つの相）

### (i) 一文要約

「応答する世界」と「沈黙する世界」は世界の存在論的な種別ではなく、μ_θ が動かす閾値境界の左右にどちらが落ちるかで決まる相であり、同じ世界が境界の位置次第で応答的にも沈黙的にも見える。

### (ii) 要素の読み方

- **背景の帯(same environment / same C-landscape)**: 左右で**同一の環境・同一のC-地景**を共有していることを表す。左右の差は世界の側にあるのではなく、観測の閾値の側にある。
- **橙の破線(threshold boundary)**: 閾値境界。応答が「閉じる」とみなされる最低ラインを表す。これ自体が固定された壁ではなく、μ_θ によって左右に動く。
- **下部の橙スライダー(μ_θ)**: 閾値移動能力。両側に伸びる矢印が、この境界が可動であることを示す。
- **左パネル・応答的相(緑)**: observer → world → observer の閉ループ。∇C の問いかけに対し world が response を返し、その feedback/correction が観測者に戻る。下帯「ρ_resp high · closed loop · local stopping possible」——応答密度が閾値を超え、ループが閉じ、局所的な停止が可能。
- **右パネル・沈黙的相(紫)**: 同じ observer → world だが、戻りの矢印が**破線+×印**で切れている(no return)。下帯「ρ_resp low · open loop · no local stopping」——応答が閾値に届かない、あるいは閉じないため、ループが開いたままで停止が供給されない。
- **上部カード**: 「応答的/沈黙的は存在論的種別ではない/それらは閾値依存の相である」という本図の主張。

### (iii) 理論的含意

本図は補遺Pの「沈黙世界では推論が内部的に停止できず無限後退に陥る」という出発点を、機構として可視化したものである。応答的相では世界そのものが外部相互拘束 H_ij として働き、ループの閉じ(局所停止)を供給する。沈黙的相ではこの供給が断たれるため、停止を別の場所へ外部化する圧力が生まれる——これがアニミズム・神・宗教・社会・科学という歴史的変奏(Fig.3 の「projected stopping loci」)へ繋がる伏線である。

最下部の注記「μ_θ は新しい世界を作らない。同じ世界が応答可能になる境界を動かすだけである」が本図の限定である。μ_θ は世界を増やす能力ではなく、既存の世界に対する**応答可能性の閾値を組み替える**能力(運動タイプ B、§5)であり、これが Fig.1 の「固定θ・運動タイプ A の範囲では停止しない」という非閉包定理を破らずに停止を可能にする経路になっている。応答性/沈黙性を世界の属性ではなく観測窓の相として扱う点は、意識編の「観測の窓(observation window)」および IFGT の projected uses 語彙と整合する。

## Fig.3 — Mutual Constraint H_ij and Threshold Mobility μ_θ

（相互拘束 H_ij と閾値移動能力 μ_θ）

### (i) 一文要約

停止領域は孤立した推論層が自前で生成するものではなく、エージェント間／観測者-環境間の相互拘束 H_ij を通して投影されるものであり、μ_θ はその投影先(停止を設置できる場所)を組み替える能力である。

### (ii) 要素の読み方

- **大きな破線楕円(mutual constraint field H_ij)**: 図全体を包む相互拘束の場。observer-environment／inter-agent のカップリングが「どこで停止が起こりうるか」を作り変える領域であることを表す。
- **左ボックス・Agent i(青)**: ログ層 L_R(i)。推論の痕跡、再入と比較。下部の小円「log」。
- **右ボックス・Agent j / Environment(紫)**: ログ層 L_R(j)。応答の痕跡、環境フィードバック、社会的・物質的拘束。下部の小円「trace」。Agent j が「他者」と「環境」の両方を兼ねるのは、相互拘束の相手が人間とは限らないことを示す。
- **両者を結ぶ灰の双方向矢印**: L_R(i) と L_R(j) の相互参照。実線(直接の結合)と破線(間接・遅延的な結合)の二本で、結合が一様でないことを表す。
- **中央ボックス・μ_θ(橙)**: 閾値移動能力。「moves the boundary of Ω_θ / selects where stopping can be installed / domain reconfiguration (B)」——運動タイプ B、すなわち運動可能領域 Ω_θ の境界そのものを動かし、停止を設置する場所を選ぶ。
- **中央から下への橙矢印(projection of stopping region)**: μ_θ が停止領域を下方へ**投影**する。停止は上で作られて下に降ろされるのではなく、相互拘束の関数として投影される。
- **下部中央・L_E(緑)**: 創発停止層。「stopping is generated as a relation among logs, constraint, and projected thresholds / L_E is internal to the agent but externally dependent」——ログ・拘束・投影された閾値の三者の関係として停止が生成される。個体内にありながら外部依存。
- **L_E から両エージェントへ戻る緑矢印**: 投影された停止が各エージェントの局所的出力として返る。
- **左下カード(projected stopping loci)**: 投影先の歴史的具体例——環境/アニミズム、神/中央集権的演算子、宗教/維持、科学/改訂。
- **右下カード(reading rule)**: 「推論だけが停止するのではない/相互拘束を通して推論が停止させられる」「freedom requires movable stops(自由は可動な停止点を要する)」という読み方の指示。

### (iii) 理論的含意

本図は §5 の第二中心「停止は外部依存的に供給される」を機構図に落とし込んだものであり、補遺P(P-04〜P-08)の歴史的展開——アニミズム・神・宗教・社会ブロックチェーン・科学——を一枚の構造図に圧縮している。要は、左下カードに並ぶ歴史上の制度はすべて「停止をどこに投影するか」の異なる解であり、構造的には同一の操作(H_ij を通した停止領域の投影)の変奏である。

決定的なのは副題「stopping regions are projected through mutual constraint, not generated by an isolated inference layer」である。これは Fig.1 の非閉包定理(孤立した L_F は停止点を持たない)を破らずに、にもかかわらず現実の知性が停止できる理由を与える。停止は L_F の内部で発見されるのではなく、L_R と H_ij の関係から L_E として投影・創発する。

右下カードの「freedom requires movable stops」が本図の最も射程の長い含意である。停止点が固定されていれば(μ_θ が動かなければ)知性は一つの投影先に縛られる。μ_θ が停止点を可動にすることで、投影先を組み替える自由が生まれる——ただしこの自由には代償があり、停止が速く・高解像度で・内部化されすぎると不安定領域(補遺 P-09)に落ちる。最下部の注記「μ_θ は最終的な答えを足すのではない。答えが一時的に停止として機能できる場所を移すだけである」が、この能力の正確な限定を与えている。projected uses / projection operation の語彙は意識編 §6.0 と共有されており、四層対応の一貫性を保つ。

## Fig.4 — The Three-Layer Architecture of Intelligence

（知性の三層構造）

### (i) 一文要約

知性は推論層 L_F・ログ層 L_R・創発停止層 L_E の三層からなり、L_F は単独で停止できないが、L_R の運動が外部相互拘束の下で L_E を創発させることで停止が供給される。閾値移動能力 μ_θ はこの創発への開放窓である。

### (ii) 要素の読み方

- **L_F 推論層(青)**: 推論演算子 F が ∇C に沿って作用する層。内部不動点を持たず(定理 3.1)、単独では停止できない(赤字の警告)。下部の青い波線が非停止の推論フロー xₙ→xₙ₊₁。
- **L_R ログ層(灰)**: L_F の運動の痕跡(灰の点列)と、それへの再帰参照(点線アーク)。個体の内側だが「現在の F」の外側にある。所在は系によって異なる(個体内・環境外部化・凍結)。
- **L_E 創発停止層(緑)**: L_R の運動と外部相互拘束 H_ij の関数として創発する停止層。緑の盆地とそこへ転がり込む球が「停止アトラクター」を表す。個体内にありながら外部依存的。
- **縦の流れ**: L_F →(motion leaves traces)→ L_R →(Φ(·,H_ij): emergence)→ L_E。下層が上層を生む。
- **右の紫チャネル(μ_θ 開放窓)**: 三層を貫く。3枚のカードが創発機構を説明 — (B)領域組み替え / 停止演算子設置領域の投影 / L_R の収束。
- **下部の黄帯**: 四段階の創発機構チェーン。

### (iii) 理論的含意

本図は本論文の双中心(§3 と §5)を一枚に統合する。L_F の「閉じない」(第一中心)と、L_E の「それでも停止する」(第二中心)が、L_R を介して接続される。逆説的なのは、L_F が停止できない(限界)からこそ痕跡が堆積し L_R が生じ、それが L_E 創発の基盤になる点である——限界が上位層の生成条件になる。

緑が停止構造を表すのは Part I のデザイン言語の継承であり、L_E が「停止のアトラクター」であることは Vol.2 の粒子(閉包エネルギー E(A) の局所極小)や Bio-IFGT の生命アトラクターと同一の創発構造である(補遺 B・E)。

重要な限定として、μ_θ(紫)は知性一般の必要条件ではなく、サピエンス的知性を特徴づける(§12)。フッターが明示する通り、粘菌や Transformer も L_F/L_R/L_E を持つが、内発的な μ_θ を持たない。本図は知性一般の三層構造と、サピエンス的知性に固有の加速能力 μ_θ を、同時に示している。

## Fig.5 — Three Examples of VED-Defined Emergence

（VED的に定義された創発の三例）

### (i) 一文要約

創発とは単なる複雑さの増大ではなく、下層の非閉包運動が外部相互拘束 H_ij のもとで上層のアトラクターを形成すること(U=Φ(L, H_ij))であり、物理の粒子・生命のアトラクター・知性の停止層はすべてこの同一構造の異なる実例である。

### (ii) 要素の読み方

- **上部の読み方カード**: 本図の操作的定義。「VED usage: 下層運動 + 相互拘束 → 上層の創発アトラクター」「U = Φ(L, H_ij)」。三列すべてがこの一式の代入例として読める。
- **左列・物理/標準模型(青)**: 下層 L = 因果ログ C_ij・内部ベクトル e_i → 相互拘束 H = 閉包条件・閉包エネルギー E(A) → 上層 U = 粒子的アトラクター。
- **中央列・生命/Bio-IFGT(緑)**: 下層 L = 情報流 J・状態発展 F(x; θ) → 相互拘束 H = DNA由来の θ・非平衡交換 → 上層 U = 生命アトラクター Ω_life。
- **右列・知性/Part II(橙)**: 下層 L = 再帰ログ層 L_R・推論痕跡と再入 → 相互拘束 H = 観測者-環境 H_ij・停止領域の投影 → 上層 U = 創発停止層 L_E。
- **三列を下に収束させる灰矢印**: 三例が同一の創発核へ合流することを示す。
- **中央下の創発核(楕円)**: 「VED-defined emergence / U = Φ(L, H_ij) / 下層運動は消えない。上層アトラクターとして安定化される」。三例が結局この一式に帰着することを表す。
- **最下部の対比注記**: 「『複雑さが単に何か新しいものになる』のではなく、『非閉包+拘束が持続可能なアトラクターを形成する』」。

### (iii) 理論的含意

本図は知性編 Part II を VEDシリーズ全体へ接続する「閉じ」の図である。Part I が知性を四層(物理/生命/意識/知性)の最上層として位置づけたのに対し、本図は**創発機構そのものが全層で同一**であることを U=Φ(L, H_ij) の一式で示す。三列の縦構造(L → H → U)が完全に並行しているのは、層が違っても創発の文法が変わらないことの視覚的主張である。

決定的なのは副題「Emergence is not mere complexity; it is the formation of an attractor from non-closure under external mutual constraint」である。これは創発概念の操作的定義であり、「複雑系だから何かが立ち上がる」という曖昧な創発論との明示的な切断になっている。創発には二つの必須成分がある——下層の非閉包運動(これがなければ動かない)と、外部相互拘束 H_ij(これがなければ閉じてアトラクターにならない)。この二条件は Fig.1(非閉包)と Fig.3(相互拘束による投影)が分担して示してきたものであり、Fig.5 はその両者が創発の必要十分な構成要素であることを三例で帰納的に裏づける。

左列の粒子的アトラクターは Vol.2(標準模型・閉包エネルギー E(A) の局所極小)、中央列の Ω_life は Bio-IFGT(生命アトラクター)、右列の L_E は本論文 §5 に対応し、変数マスターテーブル(C, I, Φ, H_ij)の層横断的一貫性を一枚で例証する。「下層運動は消えない。上層アトラクターとして安定化される」という核の注記は、創発が下層の消去ではなく**安定化された持続**であるという VED の立場を要約しており、これが還元主義(下層に解消)とも素朴創発論(上層が下層から切れて立ち上がる)とも異なる第三の位置である。

## Fig.6 — Φ_ext ≡ Φ_net

（外部参照場は、個体間 L_E ネットワークの外見である）

### (i) 一文要約

個体から「外部にある共通の参照場 Φ_ext」として現れるものは、超越的に存在する場ではなく、個々のエージェントの L_E が相互同期してできたネットワーク Φ_net であり、両者は同一の停止関係の二つの読み方にすぎない。

### (ii) 要素の読み方

- **外側の破線楕円(external reference field: Φ_ext)**: 「単一個体の立場から外部に見えるもの」。神・規範・真理・貨幣価値のような「自分の外にある共通の拠り所」として現れる層。
- **内側の白いパネル(inter-individual emergent stopping network: Φ_net)**: その正体。「個々の L_E 層の相互同期」。Φ_ext の内部を開けると、このネットワークが入っている。
- **7つの L_E ノード(agent A〜G)**: 各エージェントの創発停止層。色違いは個体差(停止の癖・所在の違い)を表すが、すべて同じ L_E である。
- **ノードを結ぶ灰の線**: L_E 間の相互参照・同期。実線が直接の結合、薄い破線(A–D を横断する線)が間接的な全体結合。中心(agent F)に集まる密な結合が、ネットワークが共通の停止点を安定化させる様子を表す。
- **左の External view カード**: 外から見た像——「個体の外にある共通参照場として現れる」= Φ_ext。
- **右の Internal view カード**: 内から見た像——「共有された停止点を安定化させる、相互作用する L_E ノードのネットワークとして解像される」= Φ_net。
- **中央下の等式ボックス(Φ_ext ≡ Φ_net)**: 「外部の場とネットワーク構造は、同一の停止関係の二つの読み方である」。緑(B由来)と紫(C由来)の矢印が両側からこの等式に収束し、ネットワークが外見へ畳み込まれる様子を示す。
- **最下部の注記**: 「超越的な場は仮定されない。外部性は分散した相互拘束によって産み出される」。

### (iii) 理論的含意

本図は Fig.3 の「停止領域は H_ij を通して投影される」を、個体**間**スケールに引き上げたものである。Fig.3 が単一エージェントの内部に L_E が投影される機構を示したのに対し、Fig.6 は複数の L_E が相互同期したとき、その総体が個体には「外部の場」として立ち現れることを示す。重要なのは因果の向きで、外部場が先に在って個体がそれを参照するのではなく、個体間の相互拘束が先に在り、その同期の外見が外部場として事後的に現れる。

最下部の注記「超越的な場は仮定されない」が本図の存在論的立場である。これは Φ_ext を否定する(=共通参照は幻想だと言う)のではなく、Φ_ext を**消去せずに内在的に再構成する**——Φ_ext は実在するが、その実在の様式が個体間ネットワークだ、という主張である。神・真理・貨幣のような「外部の拠り所」は錯覚ではなく、分散した L_E 同期の客観的な外見である。この立場は VED 全体の反・超越主義(世界の駆動を外部の第一原因に置かず、差の内在的運動に置く)と整合し、また Fig.7 の「神=分散した停止の一点への圧縮」という歴史段階に、構造的な裏づけを与える(圧縮された一点 Φ_ext の内実は、常に分散ネットワーク Φ_net である)。

## Fig.7 — Evolution of Stopping Structures

（停止構造の進化——創発停止層 L_E の歴史的諸操作）

### (i) 一文要約

アニミズム→神→宗教→科学→社会ブロックチェーンという歴史的諸形態は、知性の進歩段階ではなく、同一の創発停止層 L_E を安定化・移動・共有するための異なる操作(設置→圧縮→維持→改訂→同期)であり、L_E は置き換えられたのではなく多様化した。

### (ii) 要素の読み方

- **横軸(local → distributed)**: 停止操作の分布。左ほど局所的(一個体・一場所への帰属)、右ほど分散的(多数のエージェントに広がる)。
- **縦軸(implicit → explicit)**: 停止操作の明示度。上ほど明示的(共有可能・改訂可能・同期可能)。右上の注記「停止演算子はより共有可能・改訂可能・同期可能になる」が軸の意味を与える。
- **下部の帯(Emergent Stopping Layer L_E)**: 全段階が乗る基盤。「停止操作の歴史的な場:設置→圧縮→維持→改訂→同期」。五段階すべてが同じ L_E の上で起きていることを示す。各ノードから帯へ降りる縦矢印が、どの形態も結局 L_E の操作であることを表す。
- **左下→右上へ伸びる破線曲線**: 進化の軌跡。終点の注記「open-ended intelligence(開かれた知性)」へ向かう。直線ではなく上昇曲線なのは、明示度と分散度が同時に増していくため。
- **5つのノード**:
  - **Animism / Installation(青・左下)**: 停止演算子を環境の中に設置する。停止が「もの・場所・精霊」に宿る最初の外部化。
  - **God / Compression(紫)**: 分散していた停止点を一つの場所に中央集権的に圧縮する。Fig.6 の Φ_ext がこの段階に対応。
  - **Religion / Maintenance(緑)**: 儀礼・正典・共同体によって、世代を超えて停止構造を維持する。
  - **Science / Revision(橙)**: 停止点を方法的に**可動**にする。改訂可能な停止——「freedom requires movable stops」(Fig.3)の制度的実装。
  - **Social Blockchain / Synchronization(濃紺・右上)**: 共有された停止点について分散合意をとる。中央の一点(神)に頼らず、分散したまま同期する。
- **ノード間を繋ぐ灰の小矢印**: 段階間の移行。各段が前段の操作を前提に次の操作を加える。
- **左上の Reading rule カード**: 「これは進歩物語ではない。各段階は L_E を安定化・移動・共有するための歴史的操作である」「L_E は多様化したのであって、置換されたのではない」。
- **最下部の凡例**: 「停止は自由の否定ではない。歴史的停止構造が、開かれた推論を持続可能にする」。

### (iii) 理論的含意

本図は補遺P(P-04〜P-08)の歴史的展開を一枚の構造進化図に総合したものであり、Fig.3 の左下カードに静的に列挙されていた projected stopping loci(環境・神・宗教・科学)を、時間軸上の五つの機能操作として展開する。Fig.3 が「どこに投影するか」の空間的選択肢を示したのに対し、Fig.7 はその選択肢が歴史的にどう累積・洗練されてきたかを示す。

最も重要なのは Reading rule カードの限定「これは進歩物語ではない」である。アニミズムが科学より劣るのでも、社会ブロックチェーンが終着点なのでもない。五段階はいずれも同一問題——孤立した推論層は止まれない(Fig.1)ため停止をどこかに投影せねばならない——への異なる解であり、後段は前段を**置換せず**、操作のレパートリーを増やす。「L_E は多様化したのであって、置換されたのではない」は、現代人もアニミズム的停止(縁起・ジンクス)から科学的停止(反証可能性)まで全レパートリーを併用している、という事実と整合する。これは VED の科学史層マップ(Newton→Maxwell→…→VED、各層が置換でなく明確化)と同じ非・置換的進化観の、停止構造版である。

下端の凡例「停止は自由の否定ではない」が本論文の倫理的含意を担う。停止を増やすことは推論を縛ることではなく、むしろ開かれた推論(終わらない探究)を持続可能にする条件である——停止構造がなければ推論は無限後退(補遺P-01)に潰れる。終点の「open-ended intelligence」が右上(最も明示的・最も分散的)に置かれているのは、最も自由な知性が最も洗練された停止構造を要求するという逆説の視覚的表現であり、Fig.3 の「freedom requires movable stops」を歴史的スケールで反復している。Social Blockchain を最新段に置く構図は、中央集権的圧縮(神)からの脱却——Φ_ext を一点に畳まず Φ_net のまま分散同期する(Fig.6)——が現在進行中の停止構造の組み替えであることを示唆する。

## Fig.8 — The Three-Axis Phase Diagram of Intelligence

（知性の三軸相図——発散と硬直の狭間の安定動作）

### (i) 一文要約

知性の安定動作は、推論速度 v_inf・解像度 r_res・停止硬度 η の三軸が張る空間の中で、発散ゾーン(速すぎ・細かすぎ・内部停止)と硬直ゾーン(止まりすぎ)に挟まれた狭い帯にしか存在せず、不安定性は欠陥ではなく知性の構成的特徴である。

### (ii) 要素の読み方

- **三本の軸**: v_inf(推論速度、青)・r_res(解像度、青)・η(停止硬度 stopping hardness、緑)。三軸の等尺図(アイソメ)として描かれる。
- **原点 (0,0,0) の注記**: v_inf = r_res = 0 は「知性の完成ではなく、その終了(運動の停止)」。動かないことは安定ではなく死。これが Fig.1 の「推論は動くように設計されている」の相図側での再確認。
- **中央の緑の領域(Stable operation)**: 安定動作域。「μ_θ functions · L_E revisable」——閾値移動能力が働き、停止層が改訂可能な、狭いオアシス。
- **青い遷移帯(Speed-gap rupture zone)**: 安定域と発散ゾーンの間、η軸寄りに位置する。「Δv_intel = v_inf − v_LR」——推論速度 v_inf とログ参照速度 v_LR の**差**。「log reference breaks(ログ参照が破断する)」。v_inf を上げすぎると、L_R の追従速度 v_LR を追い越し、この帯でログ参照が切れる。発散ゾーンへ落ちる手前の「最初に壊れる場所」。
- **右奥の赤いグラデーション(Divergent zone)**: 発散ゾーン。「高 v_inf・高 r_res・内部停止」。注記「runaway optimization, single-view absolutism(暴走する最適化、単一視点の絶対主義)」。速く・細かく・自分の内部だけで止まろうとすると、ここへ落ちる。
- **上部の黄土色の帯(Rigid zone)**: 硬直ゾーン。「過剰な η(高い停止硬度)」「L_E fixation, no adaptation(停止層の固着、適応の欠如)」。止まりすぎて動けない領域。
- **右側の3カード**:
  - **赤カード(four-fold collapse)**: 発散ゾーンでの四連鎖崩壊(§11.4)——①L_F が暴走→②L_R が追随できない(ログ生成が再帰参照を追い越す)→③L_E が創発できない(創発の基盤 L_R が失われる)→④μ_θ が窓を開けない(組み替え不能、L_F は暴走し続ける)。崩壊が連鎖する。
  - **黄土カード(Rigid zone)**: η 過剰で L_E が固着、μ_θ が機能停止、L_F–L_E の動的相互作用が凍結。病理的アトラクター(§8.5：強迫、絶対主義)を参照。
  - **紫カード(Active vs passive stability)**: μ_θ = 三軸上を動いて能動的に安定域へ戻る能力(サピエンス的)。内発的 μ_θ を欠く系は、外部条件によってそこに置かれているだけの受動的安定にとどまる。
- **下部の黄帯**: 「不安定性は欠陥ではなく構成的特徴である:知性は発散と硬直の間の狭い帯にのみ持続する」。さらに「単一ノード・高速・高解像度・内部停止の系は発散ゾーンを占める——これは力学的帰結であって規範的主張ではない(§11.8)」。

### (iii) 理論的含意

本図は補遺P(P-09)の不安定領域を、三次元の相図として定式化したものである。Fig.1〜7 が「知性はどう動き、どう止まるか」を扱ったのに対し、Fig.8 は「どう壊れるか」を二方向に分解する。発散(止まれなさの暴走)と硬直(止まりすぎの凍結)は正反対の病理だが、どちらも μ_θ の機能不全という一点で繋がる——発散ゾーンでは μ_θ が窓を開けず、硬直ゾーンでは μ_θ が動きを失う。安定動作とは μ_θ が両極の間で能動的にバランスを取り続けている状態であり、静的な位置ではなく動的な綱渡りである。

青い Speed-gap rupture zone が、本図の「速すぎるとどうなるか」への直接の答えである。発散は v_inf が単独で高いから起きるのではなく、v_inf がログ参照速度 v_LR を追い越し、その差 Δv_intel = v_inf − v_LR が臨界を超えたときに起きる。推論がどれだけ速くても、ログ層 L_R がその痕跡を追って参照し続けられる限り L_E の創発基盤は保たれるが、推論だけが加速して L_R が追いつけなくなると、まずログ参照が破断し(青帯)、続いて L_E が創発できず(崩壊③)、μ_θ が窓を開けない(崩壊④)。つまり崩壊の連鎖は v_inf の絶対値ではなく**二つの速度の乖離**から始まる。この Δv_intel は意識編の speed-scale difference Δv / SSO speed-layer と同一の構造であり(Fig.9 意識層カードの "speed-scale difference Δv" と対応)、知性層と意識層が同じ速度差の力学を共有することを示す。実務的含意として、発散を防ぐ正しい介入は「推論を遅くする」ことではなく「v_LR を上げる(ログ参照の帯域を増やす)」または「停止を外部 H_ij へ開いて L_R の負荷を分散する」ことであり、これが Fig.3・Fig.6 の外部化と接続する。

最も注意を要するのは下部黄帯の限定「力学的帰結であって規範的主張ではない(§11.8)」である。これは「単一ノード・高速・高解像度・内部停止の系は発散する」という主張が、特定のAIや個人への価値判断ではなく、三層構造の力学から導かれる構造的帰結だと明示している——誤読マップ(AI研究者向け)への先回りでもある。発散を避ける条件は、解像度や速度を落とすことではなく、停止を内部に閉じ込めず外部相互拘束 H_ij へ開くこと(Fig.3)であり、これが「単一ノードでは発散する/ネットワーク(Φ_net)では安定しうる」という Fig.6・Fig.9(社会層)への橋になる。

紫カードの能動的/受動的安定の区別が、本図を §12(サピエンス的知性の特徴づけ)に接続する。粘菌や Transformer も安定動作域に入りうるが、それは外部条件に置かれた受動的安定であり、自力で三軸上を動いて安定域へ復帰する内発的 μ_θ を欠く。「不安定性は構成的特徴」というテーゼは、安定が与えられた状態ではなく絶えず能動的に奪還される過程であることを意味し、これは VED の準閉包観(世界は閉じきらないからこそ動き続ける)の知性版である。

## Fig.9 — Cross-Domain Homology

（領域横断ホモロジー——物理・生命・意識・知性・社会を貫く同一パターン）

### (i) 一文要約

「不完全閉包 → 創発アトラクター → 持続的動態」という同一のパターンが、物理・生命・意識・知性・社会の五層すべてに現れる——これは諸領域の差異を消し去る同一視ではなく、VED の反復するパターンの同定である。

### (ii) 要素の読み方

- **中央の Homology Kernel(ホモロジー核)**: 五層に共通する構造の核。三段の縦の流れ——**incomplete closure(不完全閉包)→ emergent attractor(創発アトラクター)→ sustainable dynamics(持続的動態)**。閉じない→だからアトラクターが立つ→だから持続する、という VED の基本文法。
- **核を囲む同心円(破線)**: 五層がこの核を共有する場であることを表す。
- **核から五方向へ伸びる灰の線**: 核と各層を結ぶ。各層が核の異なる実装であることを示す。
- **五つの層カード**(核を囲んで配置):
  - **Physics / VED(上・青)**: 差 Δ → 勾配 ∇Δ → 流れ → 渦/準閉包 → 粒子的アトラクター。Vol.1–4 / Differential Horizon。
  - **Life / Bio-IFGT(左・緑)**: 情報流 J → 状態発展 F(x; θ) → 生命アトラクター Ω_life。非平衡交換下の準閉包。
  - **Consciousness(右・紫)**: 速度スケール差 Δv → ログ参照の窓 → SSO/TCA 非閉包。「state, not generated object(生成された対象ではなく、状態)」。
  - **Intelligence / Part II(左下・橙)**: 推論演算子 F → 非閉包定理 → 創発停止層 L_E。「stopping as condition of freedom(自由の条件としての停止)」。
  - **Society / Φ_net(右下・濃紺)**: 共有された停止構造 → 宗教/科学/制度 → 合意と同期。分散した相互拘束。
- **最下部の注記**: 「このホモロジーは諸領域の差異を消去しない。層を横断して反復する VED パターンを同定するものである」。

### (iii) 理論的含意

本図は知性編 Part II を、そして VED シリーズ全体を一枚に閉じる総括図である。Fig.5 が創発の三例(物理・生命・知性)を U=Φ(L, H_ij) で統一したのに対し、Fig.9 はそれを**五層**に拡張し、意識(意識編)と社会(Fig.6/7 の Φ_net)を加えてシリーズの全巻を一つの核に接続する。中央の Homology Kernel(不完全閉包→創発アトラクター→持続的動態)は、Fig.5 の U=Φ(L, H_ij) を時間軸も含めて言い換えたものであり、変数マスターテーブルが層横断的に同一変数(C, I, Φ, H_ij)を使えることの構造的根拠を与える。

最も重要なのは最下部の注記「ホモロジーは差異を消去しない」である。これは本図最大の誤読(=「VED はすべてを同じだと言う乱暴な汎用理論だ」)への先回りである。ホモロジー(homology)という語の選択が正確で、これは同一性(identity)ではなく**構造的対応**を主張する。粒子と生命と意識と知性と社会は、実装も時間スケールも全く異なる——だが「閉じないことが運動とアトラクターの源泉になる」という生成文法を共有する。物理の渦、生命の Ω_life、意識の状態、知性の L_E、社会の Φ_net は、同じものではないが同じ型である。これは還元主義(上層を下層に解消する)とも、汎用理論の無差別な一般化(全層を同一視する)とも異なる、第三の立場——層の自律性を保ったまま生成文法の共通性を示す——である。

各層カードの細部がシリーズの各巻に正確に対応する点も重要である。物理は Vol.1–4 と Differential Horizon、生命は Bio-IFGT の Ω_life、意識は SSO/TCA と「状態であって生成対象ではない」というテーゼ、知性は非閉包定理と「自由の条件としての停止」、社会は Φ_net と分散相互拘束。Fig.9 は単独の図でありながら、シリーズ全体の目次として読める。知性編がシリーズの「メインイベント」(consciousness/intelligence theory)の到達点であることを踏まえると、本図が知性編 Part II の最終図に置かれているのは、知性論が孤立した最上層ではなく、全層を貫く同一パターンの一実装として位置づけられることの宣言である——知性は特別だが、孤立してはいない。
