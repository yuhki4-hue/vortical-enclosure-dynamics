図1｜「情報」はどこで混線するのか

実世界の関係・局所投影・言語ゲーム・概念境界

四層は記述上の区分であり、自然史の階段ではありません。社会的使用や測定も世界の中に成立する実践です。

スマホでは図を横にスクロールできます。説明は下へ。

A｜図の説明

この図は、「情報」という語の定義を一つに決めるための図ではない。同じ対象に成立する複数の関係から、各研究・社会実践が何を選び、どの語で束ね、その語が次の観測をどう導くかを示す。下段Aでは、差異、相互作用、痕跡、複製、調節、因果的利用などが、異なる系境界Σ・機構・時間幅で重なる。ここに「情報」という物体は置かない。ただし、Aの描画も世界の無媒介な写しではなく、監査を通じた暫定記述である。

Bの局所投影は、研究課題に応じた選択を表す。Shannon理論は確率的な区別、不確実性、伝達を厳密に扱う断面であり、意味へ発達する前段階ではない。Cでは、選ばれた関係が実験、推論、訂正、社会的伝達の実践の中でinformation、code、memoryなどと呼ばれる。語の輪郭は重なり、同じ語でも文脈によって包含範囲が違う。Dは、反復使用や測定規約によって境界が相対的に安定することを表すが、その形成史を確定したものではない。

右側には二つの向きを分けた。関係の再現性は命名を制約する。一方、概念は問い、変数、対照、測定方法の選択を通して、観察される区分へ戻る。この相互安定化は、言語が世界を作ることや、世界が語彙を一意に決めることを意味しない。DNAでは複製、翻訳コード、履歴痕跡、科学的表記を別のΣに分ける。走化性では感受、適応、履歴の利用、環境との循環が比較的明瞭でも、表象内容と正誤は別途監査する。混線が生じるのは、こうした違いが同じ語に圧縮され、その省略された条件が議論の途中で忘れられるときである。

四層と、矢印の読み方

層何を描くか省略してはいけない条件
A：関係網 ℛ差・相互作用・特異的応答・変換・持続・痕跡・記録・複製・調節・帰還・因果利用・生物に対する関連性・表象候補・社会的使用・測定関係。Σ・対照集合𝒟・機構M・帰結Q・応答／更新時間τ。現実の成立のマダラさと、帰属根拠の不確実さは別。
B：局所投影 πᵢ分野・課題が何を比較・測定・モデル化するか。πは選択の模式記号。厳密な射影演算や世界から一意に導かれる分解ではない。
C：使用実践 Lᵢinformation、signal、code、memory、message、representation、meaning、function、intelligence、consciousnessなどを、推論・訂正・伝達で使う。ここは自然界の分類ではなく、語の使用領域である。語は世界の物体でない。intelligenceとconsciousnessは別途監査する用語であり、意味の到達点ではない。
D：概念境界 Cᵢ反復使用、測定規約、教科書、分野慣習、制度、社会実践による暫定的・相対的安定化。文脈依存・競合・拡張が残る。各語の実際の概念史は未調査。

実線は選択・測定・命名を介する接続、破線は概念から問い・実験設計へ返る経路。成立条件の論理的含意や歴史的影響関係を表さない。上下方向に読む際も、矢印の向きを逆にして意味を変えてはいけない。

理論・用語の再配置

Shannon／通信 [1]

確率分布、不確実性、相関、通信路を扱う局所投影。意味を扱わないという課題設定は、未完成であるという評価ではない。図2では同じ手法を異なる関係に適用する横断解析として扱う。図1の投影と図2の横断解析は役割が異なる。

Bateson [2]

差が回路を通じて別の差をもたらす議論を、差・因果効果・系に相対的な関連性の近傍に配置する。M1への接続は今回の監査上の読みであり、Batesonの議論全体をM1に還元しない。表象内容や意味一般の必要十分条件として使わない。

Wheeler／It from Bit [3]

情報的な問いと装置の応答を存在論へ拡張する提案として別枠に置く。Shannon理論や量子情報理論から確立した帰結としてつながない。人物間の派生矢印を引かない。

Biological / semantic information / information ontology

biological informationは複製・発現・利用・機能などを束ねる用語群。semantic informationも維持への因果寄与と表象内容を同義にしない。philosophical information ontologyは存在論的主張を問う投影であり、機構実験の結論そのものではない。これらは使用近傍の配置で、系譜の証明ではない。

概念から問いへの帰路：二つの検査例

語問い・測定追加帰属の留保
memory何が保持され、後続応答へ使われるか。メチル化状態、神経状態、保存配列と、それぞれの刺激履歴・時間窓・対照を選ぶ。履歴依存やW2の後続利用は、過去値を明示的に表す内容を保証しない。
code対応担体、入出力型、対応写像、再割当可能性を検査する。翻訳系でR3/R4を支持しても、DNAが形質や未来を記述するとは言えない。

この二例は実験設計の読み方である。memoryという語が当該実験を歴史的に生んだ、という概念史の断定ではない。

C｜禁止飛躍

  • 同じ語 → 同じ関係構造 を自動的に推論しない。
  • 同じ対象 → 同じ情報関係 を自動的に推論しない。
  • Shannon → semantic meaning を自動的に推論しない。
  • code → representation を自動的に推論しない。
  • memory → explicit past content を自動的に推論しない。
  • concept boundary → natural boundary を自動的に推論しない。
  • repeated usage → ontological reality を自動的に推論しない。
  • empirical pattern → unique vocabulary を自動的に推論しない。
  • M4の科学的使用 → 対象分子自身のM3 を自動的に推論しない。
  • N2の成功／失敗 → N3の表象的正誤 を自動的に推論しない。

同じ語で再統合すること自体は有用な抽象化でもある。混線は、異なるΣ・局所関係・実践を省略したまま、その語から別の関係の成立を推論するときに生じる。
