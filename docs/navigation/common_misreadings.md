# Common Misreadings

This document lists common ways in which VED / IFGT terms can collapse into
familiar but unintended meanings. It is an interpretation guide, not a new
theoretical layer.

## Closure

Appears in:

- [Vol.1](../../paper/vol1/)
- [Vol.4](../../paper/vol4/)
- [IFGT](../../Information-Field-Geometry-Theory/)

Common misreadings:

- perfect closure,
- static equilibrium,
- an isolated system.

VED usage:

- effective local closure under non-closure conditions.
