# Name Misreadings

This document records common entry-layer misreadings of the repository name and
core terms. It is meant to be read before collapsing VED into familiar technical
domains such as computational fluid dynamics.

## Vortical

Common misreading:

- fluid vortex,
- computational fluid dynamics vortex,
- Navier--Stokes vortex structure.

### Common Advanced Misreadings

- dissipative structure only,
- biological self-maintenance only,
- autopoietic circulation only.

VED usage:

- recursive circulation,
- self-referential persistence,
- circulation-like formation of stable structure within a generative sequence.

Clarification:

- VED uses vortical structure as a generative concept across physical,
  biological, cognitive, and social scales. Dissipative, biological, or
  autopoietic readings may be useful neighbors, but they should not exhaust the
  term.

## Enclosure

Common misreading:

- physical container,
- cavity,
- closed box,
- literal spatial enclosure.

VED usage:

- effective local closure,
- constraint-defined regime,
- locally stabilized structure that remains under non-closure conditions.

## Dynamics

Common misreading:

- mechanical motion only,
- fluid motion only,
- simulation of moving matter.

VED usage:

- generative transformation processes,
- changes in difference, gradient, flow, constraint, enclosure, and non-closure
  across descriptive layers.

## VED

Common misreading:

- CFD framework,
- fluid-mechanical modeling program,
- Navier--Stokes-based methodology.

VED usage:

- generative structural framework,
- framework for re-situating physical, biological, cognitive, and social
  descriptions through difference, enclosure, and non-closure,
- not a replacement claim for existing physics or cognitive-science theories.
