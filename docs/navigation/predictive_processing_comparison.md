# Predictive Processing Comparison

This page is a navigation aid for readers who approach VED from Predictive
Processing. It does not claim that VED is a Predictive Processing theory, nor
that Predictive Processing is reducible to VED.

## Why This Comparison Matters

Predictive Processing-oriented readers are likely to notice themes that also
appear in the consciousness and intelligence papers:

- fast processing anticipates future states,
- error correction and updating matter,
- prediction must interact with slower structures,
- a model of cognition cannot be reduced to static representation alone.

The strongest repository connection is the consciousness paper, which explicitly
discusses prediction, error, forward models, slow-layer sedimentation, and the
limits of treating prediction as sufficient for consciousness.

## Agreement

VED / IFGT and Predictive Processing can be read as sharing several broad
orientations.

| Shared Orientation | VED / IFGT Reading |
|---|---|
| Prediction matters | Fast-layer processing includes prediction, forward models, and correction. |
| Updating matters | Sedimentation changes the terrain for subsequent prediction and referencing. |
| Errors are not mere noise | Error correction participates in immediate environmental response. |
| Processing is dynamic | Cognition is treated as ongoing movement rather than static content. |

## Difference

The explanatory focus is different.

| Predictive Processing | VED / IFGT |
|---|---|
| Often centers prediction, model updating, and error minimization. | Centers temporal non-closure, log referencing, constraint, and meaning-gradient bias. |
| Prediction is often a core explanatory primitive. | Prediction is one element inside a broader fast/slow log-referencing relation. |
| Consciousness may be interpreted through predictive architecture. | Consciousness is treated as the opening of log referencing within a non-closure window. |

The consciousness paper states that predictive processing may be a necessary
element, but is not treated as a sufficient condition for consciousness.

## Possible Relation

Within this repository, Predictive Processing may be interpreted as a local
fast-layer component of a broader log-referencing account. A cautious
formulation is:

> Predictive Processing can be read as describing important fast-layer
> anticipatory and updating dynamics, while VED / IFGT asks when those dynamics
> become sedimented, re-referenceable, and non-closed across time scales.

This possible relation does not imply identity between the frameworks.

## Interpretation Boundaries

Do not read this comparison as claiming that:

- VED proves Predictive Processing,
- Predictive Processing is reducible to VED,
- VED replaces Predictive Processing,
- prediction alone explains consciousness in the VED account,
- all VED constraint dynamics are prediction-error dynamics,
- the repository already contains a complete formal translation between
  Predictive Processing and VED.
