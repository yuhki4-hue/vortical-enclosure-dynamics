# Concept Traps

This document lists high-frequency conceptual attractors that can cause human
or AI readers to collapse VED / IFGT terms into familiar but unintended
meanings.

For a broader list, see [Common Misreadings](common_misreadings.md).

## Closure

Common destination:

- equilibrium,
- completion,
- perfect sealing,
- final state.

VED usage:

- effective local closure,
- locally stabilized structure,
- not absolute completion.

Related links:

- [Common Misreadings: Closure](common_misreadings.md#closure)
- [Vol.1 minimal axiom](../../paper/vol1/sections/minimal_axiom.tex)

## Non-Closure

Common destination:

- failure,
- incompleteness,
- lack of structure,
- unresolved defect.

VED usage:

- structural condition preventing absolute closure,
- condition under which generated structures remain dynamically open.
- absolute closure is *unreachable*, not merely *not-yet-reached*,
- complete closure is incompatible with continued existence, so non-closure
  is constitutive rather than a defect.

Related links:

- [Common Misreadings: Non-Closure](common_misreadings.md#non-closure)
- [Vol.4](../../paper/vol4/)

## Log

Common destination:

- computer log,
- memory record,
- stored data sequence,
- subjective narrative.

VED / IFGT usage:

- sedimented causal history,
- registered difference,
- trace through which temporal order and structural persistence become
  describable.

Related links:

- [Common Misreadings: Log / Causal Log](common_misreadings.md#log--causal-log)

## Information

Common destination:

- Shannon information only,
- stored data,
- semantic content,
- mental content.

IFGT usage:

- quasi-closure / constraint structure,
- trace left when difference does not fully dissipate,
- structure that biases subsequent difference chains.
