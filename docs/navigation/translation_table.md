# Translation Table

This table helps readers follow how recurring terms move across VED, IFGT, and
application-layer papers. It is a navigation aid, not a new formal definition.

| VED Term | IFGT / Application-Layer Reading | Caution |
|---|---|---|
| Difference | Informational distinction or registered difference | Do not read as a fully specified microscopic ontology in every context. |
| Gradient | Constraint direction / directional pressure | The local mathematical form depends on the paper. |
| Flow | State movement / information movement | Not always a literal fluid flow. |
| Vortex | Recirculation / recursive persistence | Not always a physical vortex in the hydrodynamic sense. |
| Enclosure | Effective local closure / quasi-closure | Not perfect closure. |
| Non-closure | Boundary condition / open horizon | Not mere failure or absence of structure. |
| Constraint | Physical barrier, potential gradient, probability bias, viability condition, or stopping/consensus structure depending on layer | Not only external force; see [Constraint Dynamics](constraint_dynamics.md). |
| Projection | Structural window between layers | Not psychological projection unless explicitly stated. |
| Log | Trace, sedimentation, or historical accumulation | Not only a computer log. |
| Stopping layer | Stabilizing layer for non-closed inference | Not the negation of intelligence or freedom. |
