Concept map of “information” v0.3-direct-source-audit · built 2026-11-08

Bounded English-language reconstruction from an eight-item starting corpus. v0.3 · release candidate 4: the v0.2 map (frozen; IDs kept) re-checked against the supplied source files. Every node and link shows source genre, verification method and epistemic support as separate fields. This is a fixed-framework re-audit, not an independent new reconstruction. Spatial positions are never evidence.

Overview

Scope. Uses of English “information” in the starting corpus (Shannon; Grünwald & Vitányi; two editions of the SEP entry on semantic conceptions; Dretske's précis; Bateson; the SEP entry on biological information; Landauer; Buckland). Source exposition plus reconstruction; nothing translated. Questions: what each use takes as the bearer of information; which conditions it needs; where uses connect by theorem, by borrowing, by analogy, or not at all. Excluded: quantum and Fisher information, the BBS commentaries and Dretske’s reply. Shannon Parts III–V and Landauer’s full article are available in v0.3; only the cited portions have been checked, not every claim in every work.
How the sources were read. v0.2 read all sources through a model-mediated web extraction step. v0.3 re-checked them against supplied files: each cited passage is matched automatically against my own text extraction of the stated page or HTML paragraph, and two-column pages were confirmed on page images. The v0.2 access record is preserved unchanged (“Sources & limits”); v0.2 locations are shown as legacy.
Read the map cautiously. Of 317 records, 303 have complete direct-source verification (298 text, 5 page-image), 6 remain partial, and 8 editorial constructs are not applicable to source verification. The legacy “full” coverage field includes those 8 editorial records, so it does not mean 311 directly verified records. 117 records rely only on review articles; the primary works those reviews discuss were not checked. Mixed primary/review records also occur.
R023 is an inferred comparison between uses of “meaningful”, not an explicit comparison made by either author. R100 is an unresolved candidate contradiction, not an established disagreement. The six partial records retain unchecked E1/E2 material. These limitations are part of the map, not defects erased by passing software tests.

Shared legend (all views)

v0.3 evidence axes (kept separate on every record): genre primary / review / editorial · verification direct-file text / direct-page image / indirect / not checked · support explicit / conditional / inferred / disputed / unresolved. A “primary” genre is not proof that the text was read; the v0.2 “evidence” label is kept only as legacy.

Claim strength (how strong the stated claim is: definitional … conjectural) and evidence (how well I could attest it: primary-explicit … editorial) are separate fields on every link. These legacy labels are not a substitute for the v0.3 verification and support fields. Directly checking a passage does not establish an inferred cross-theory connection.

Meaning of spatial layout

  • Fig 1: boxes are editorial groupings by bearer. Box order and chip order carry no meaning. A dashed chip is a secondary placement; ⚑ marks a forced placement.
  • Fig 2A / Fig 3: matrices. Row and column order is by ID, not by importance.
  • 3D view: the vertical axis is the node type (categorical layer). Layer order is arbitrary: “use” above “condition” does not mean uses rank above or ground conditions. Horizontal positions come from a deterministic force simulation on ledger links: linked nodes are pulled together, all nodes push apart. Distance therefore reflects only how links happen to connect in this version — not similarity, not measurement, not evidence. A “free” mode drops the type layers.
