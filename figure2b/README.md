# 図2B v4 — three.js 関係探索プロトタイプ

「情報」という実体の図ではなく、同じ対象に成立する変換・記録・機能・調節・表象・使用などの関係を探索する静的HTMLです。生物・人工物を一列の発展段階に並べません。

## 開く・公開する

ZIPを展開して **index.html** をブラウザで開いてください。外部通信・ビルド・アカウントは不要です。WebGLを利用できる現代的なブラウザが必要です。iOSのファイルプレビュー内ではJavaScriptが動作しないことがあります。その場合はGitHub Pages上のURLをSafariで開いてください。

GitHub Pagesでは、このディレクトリの全ファイルを公開対象ディレクトリ（リポジトリルートまたはdocs等）に置きます。相対パスのためプロジェクトPagesでも使用できます。公開設定自体はリポジトリ側で行ってください。この納品物は未公開です。

ローカルHTTPを使う場合：

```sh
python3 -m http.server 8000
```

そのディレクトリで起動して `http://localhost:8000` を開きます。file://でも動くよう、ES Modules・fetch・外部フォントは使用していません。

- index.html — ページ構造、注記、操作パネル
- style.css — 淡色デザイン、ラベル、モバイルパネル
- data.js — 宣言的なノード・領域・機構・経路・事例データ

- README.md — 本文

依存はthree.jsのみです。直接ファイルを開く用途に合わせてclassic script対応版を固定しました。最新版追随を意図する構成ではありません。外部API、CDN、トラッキング、データ送信はありません。描画は操作・リサイズ時のみ更新し、不要な連続アニメーションを避けています。

## 軸は模式的な読解軸

- X：持続・更新の時間射程。一過的差異／記録・複製・継承・制度化。
- Y：変換・利用の構成。直接相互作用／差異依存変換／規則担体の分離／コード・体系的対応。
- Z：組織化・維持・意味拘束への埋込み。局所作用／因果役割／組織的維持／規範／表象・使用・社会的意味。

**位置・距離・体積は測定値ではありません。** 三軸に共通の尺度や順位関係を定義していません。特にZに並ぶ概念は前提の階段ではなく、独立に検査する問いです。長期継承が短期作用より上位、社会的意味が物理作用より高級、AIが生物の未完成形、という読みはしません。意味があるから持続する、規範があるから表象がある、という推移も認めません。

## 表示内容と論理文法

- 球：D、R0〜R4、W0〜W3、Kf/Ku、Fc/Fo/Fs、C0〜C3c、N1〜N3、M1〜M5の計29関係概念。
- 菱形：指定14事例＋自律ロボットの15事例。位置は一覧の代表配置であり、事例の全性質を一点へ圧縮しません。
- 四角：感受、作用、機構形成等の15機構・状態。これらが因果経路の端点です。
- 半透明領域：UI、拘束束、表象、使用、調節、記録・複製の6候補領域。
- 経路：生成・利用・維持・訂正・継承・社会的伝達。青実線は状態補償Loop A、紫破線は機構維持Loop B。その他は経路種別色です。
- 事例選択時の灰色点線：関係への参加を示す**無方向の参照線**。Focus中は明示的な関連要素を一時表示します。点線は監査上の参照で、含意ではありません。
- ShannonとKolchinsky & Wolpert：座標外の横断解析カード。意味の下位段階やM3そのものに置きません。

関係概念R・Fo・Mなどの間には因果矢印を引きません。実際の担い手・介入証拠を未指定の経路は、事例ごとに検査するテンプレートです。全ネットワークが全事例に実在するとは主張しません。初期状態では因果機構レイヤーをオフにし、関係と事例の探索から始めます。

M2の詳細にM2-c/o/s、M4の詳細にM4-f/s、M5の詳細に経験の現れ方と本人にとっての意義を分けて記載しています。

## 操作

- ドラッグ：回転。ホイールまたはピンチ：ズーム。
- 右ドラッグ、Shift＋ドラッグ、2本指移動：パン。
- キャンバスにフォーカス後、矢印キー：回転。Shift＋矢印：パン。＋／−：ズーム。
- 点・ラベル・左の一覧：詳細表示。右パネルのボタン：カメラを対象へ移動。
- 事例の関係タグ：その関係のレイヤーを有効にして詳細表示。
- 左チェックボックス：系列・領域・事例・横断解析の表示切替。
- 領域個別スイッチは親レイヤーとAND。個別領域をオンにすると親もオンになります。
- 因果経路は「因果機構・経路」をオンにしてから種類別に絞れます。
- 上部プリセット：俯瞰・調節・DNA・意味・AI比較。カメラと選択対象を変更し、現在の局所断面を一文で表示します。選択以外の事例が残ることがあります。分類・序列を作る機能ではありません。
- Reset view：カメラ・表示・検索・ラベルを初期状態へ戻す。
- モバイル：レイヤー／説明ボタンでパネルを開閉。監査パネルは下部シート、取手で高さを切替。プリセットは横スクロール。
- カメラ距離に応じて通常ラベルを減らし、重なりを回避します。選択・直接関連ラベルは優先表示し、移動したラベルに引出線を付けます。対象は左一覧からも選べます。

## データの追加

`window.FIGURE_DATA.elements` の各オブジェクトは id / label / type / group / position / description / notes / references / visibleByDefault を持ちます。事例にはsigma / mainRelations / caveatsを追加しています。

- typeはnode / region / path / example。
- 領域はscale、経路はsource / target / kind / loopを追加。
- 横断解析はspace:'panel'、position:null。3D内には置きません。
- confusions / examplesが右パネルの混同・代表例欄です。
- 追加の系列はgroupsにも記載します。
- 因果経路source/targetはgroup:'process'の機構・状態のみを参照します。
- 調査済みのΣ・𝒟・M・Q・τresponse・τupdateはnotes等に追記してください。現段階では測定値を捏造して埋めていません。

系自身による利用を主張する場合、動力学が実際に区別・利用する粒度を優先します。未利用の痕跡や記録の存在を消さないよう、W0/W1とinformation for the systemを分けます。

## 2D図との役割分担

図2Aは追加成立条件の非循環図、図2Bは実在系の因果ネットワークです。本3D版は重複帰属、境界、経路を切替探索する補助です。3Dの座標から条件の含意を読み取らず、厳密なAND/OR・理論条件は2D図／監査本文へ戻ります。

UIは独立実体ではなく関係の重なりです。外部装置を作用循環へ加えてもFoへ自動編入しません。DNAマーカーから複数の関係を参照しますが、配列・翻訳装置・細胞・系統のΣを区別します。意味＝拘束束は作業仮説で、体積も固さも測定量ではありません。

## v4.1 局所断面監査の追加

### Focus Mode

初期ON。概念・事例・領域を選ぶと、data.jsに登録した参照、領域への参加、因果機構と経路、横断解析だけを強調します。座標や距離から関係を推測しません。その他の表示済み対象は淡色で残ります。未表示レイヤーの関連要素はFocus中だけ表示し、チェックの横棒で知らせます。Focus OFFまたは選択解除で元の手動設定へ戻ります。全体俯瞰は対象未選択です。

無方向の点線＝参照／監査上の接続候補。矢印＝機構間の因果テンプレート。引出線＝移動したラベルの位置案内。この3種類は別物です。M3を選んでR3/R4が強調されても、自動的な表象の成立を意味しません。

### 監査パネル

作業定義、観測・介入する成立根拠、混同、禁止される飛躍、代表例、Σ・𝒟・M・Q・τresponse・τupdateを分けます。未登録値は未指定。拘束タイプのタグと形成履歴のタグは別表示で、根拠・範囲を展開できます。タグは参加候補であり、強度、確率、測定値ではありません。

### Σ Boundary Mode と比較

15事例に計40の境界別レコードを登録。local/body/loop/maintenance/socialのうち、未登録は無効な選択肢として表示します。境界変更は別の対象命題の評価です。FoとUIは別々の欄に表示し、拡大した境界からFoを推定しません。人間＋暖房／投与装置では人間の組織と装置保守を分離します。DNAでは配列単独と発現・複製装置を含む系を区別します。

「2事例を比較」で2つの事例と各Σを選びます。4つの組合せプリセットもあります。各セルを押すと判断理由を表示します。未設定は未評価であり、「弱い」「未確定」とは異なります。比較は合計点を作らず、概念の強弱や生命らしさを採点しません。

### 根拠の限界

Evidenceは事例＋指定Σについての作業的帰属です。●は実証または強い構成上の根拠であり、全事例の実験確認済みという意味ではありません。判断理由に条件と文献を記します。◐候補／○弱い／?未確定を区別。分類群全体への一般化を避け、未評価欄を勝手に埋めません。Fo、表象内容、AIの内生的内容は多くが候補または未確定です。経験の存在は内容帰属から推定しません。

ShannonとKolchinsky & Wolpertは座標外に固定。変数・分布・粒度等の指定を要求し、解析計算そのものは未実装です。2D成立条件図へのリンクは未設定のプレースホルダです。

### データの拡張規約

relationsはtarget/kind/reasonを持つ明示的参照。constraintTypesとformationHistoryは独立の配列、各basisに根拠を記載。auditQuestionsとforbiddenInferencesは文字列配列。auditContextはsigma/contrasts/mechanism/q/tauResponse/tauUpdate。sigmaModesにはrelations/evidence/causalPaths/analytics/auditContext/foAssessment/uiAssessment/externalConnectionsを登録します。証拠はstatus/basis/referencesを持ち、欠損は欠損として残します。レコード変更時は参照先IDの検証と日本語フォントサブセットの更新が必要です。

API: window.FigureExplorer の select / preset / setSigma / setCompare / clearFocus / fitFocus。検証用にgetState/getFocus/inspectを提供。永続保存やデータ編集のUIはありません。

検証と論理文法の自己監査はAUDIT.mdを参照してください。

## v4.2 — 実世界の境界 × 概念使用

左の **Boundary Layers** で Patchy Boundary を有効にします。「走化性のΣ横断デモ」は8境界のclaimを同時表示しますが、根拠状態を最強値へ集約しません。通常は「選択したΣのみ」です。Σを変更すると別の対象命題へ戻ります。

- Relation：根拠状態別の半透明パッチ。色と文字はclaimの状態であり、自然物のランクではありません。
- Concept：使用文脈ごとの環状の包摂表示。語は自然界の物体ではありません。輪郭の配置・面積は編集上の参照位置です。
- Both：両者を重ねます。
- Difference：A＝strongだが登録用法外、B＝同じ語に束ねる異質な関係・未確定帰属、C＝strongで登録用法内。Bの異質性はΣ・機構・根拠から読みます。一致率は計算しません。未登録は不在ではありません。
- 相互安定化：右パネルに「関係パターン→測定→命名」と「概念→問い→変数選択→測定」の別経路を表示します。実証された概念史ではなく作業仮説です。

DNA 69 claim、E. coli 41 claimの元監査をdata.jsに保持しました。各Σの監査表と参照文献へアクセスできます。M2-c/o/sなどの下位関係は同じ描画アンカーを共有しても別claimです。座標から内容を統合しません。修復・複製誤差にはKuを自動帰属せず、監査欄で表示します。

概念語の使用範囲は**編集上の比較案**です。分野全体の用法頻度・概念史の文献監査は未実施であり、conceptHistoryの起源・安定化過程はunknownです。既存の分子機構文献を命名史の証拠へ流用しません。M4とConceptual Boundaryは別です。

DNAビューは翻訳Σを開きます。DNAと走化性の比較では左右に別々のΣを指定します。Σ横断は事例全体の単一判定ではありません。Focusと比較機能は維持されています。ShannonとK&Wは引き続き座標外です。

この版は境界断面の切替を実装し、発生・進化アニメーション、拘束強度、生命度、一致率、意味度を実装しません。関係パッチの色は関係そのものの真偽ではなく、登録claimの根拠状態です。
