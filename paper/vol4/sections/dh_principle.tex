\section{The Differential Horizon Principle}

\label{sec:principle}

From the preceding discussion,
a structural constraint emerges.
The \DH{} is not a wall located somewhere in spacetime.
It is a descriptive boundary that appears whenever a
spacetime-generated observer attempts to describe the condition
from which spacetime itself is generated.
It is the limit at which a description based on difference tries
to describe the absence of difference.

\medskip
\begin{quote}
\textbf{\DHP{}:}\\
Observation measures difference from within generated spacetime;
where difference itself is no longer available,
description encounters a horizon.
\end{quote}
\medskip

This principle can be expressed in three propositions.
We refer to them as Propositions 1, 2, and 3
of the \DHP{}.
Here,
a generated domain means any domain in which differences have already
become describable,
including but not limited to spacetime.

\begin{enumerate}
  \item Observation can measure only differences that have already
  entered a generated domain.
  \item The absence of difference cannot appear as an ordinary state
  within the spacetime generated from difference.
  \item Every attempt to describe the disappearance of difference
  from within spacetime therefore produces a horizon of description,
  not a final object of description.
\end{enumerate}

\subsection*{The Chain of Necessity}

These propositions are not independent.

\medskip
\begin{quote}
They form a necessary structural chain.
\end{quote}
\medskip

Because observation operates through difference,
it can register only what has entered a generated domain.

Because the absence of difference would erase the condition
under which such registration is possible,
it cannot appear as one more state inside generated spacetime.

Because it cannot appear as an ordinary state,
the attempt to describe it from within spacetime yields a
descriptive boundary.

\medskip
\begin{quote}
The \DH{} is not an external prohibition.\\
It is the internal signature of generated description
reaching the condition that would erase its own difference.
\end{quote}
\medskip

\subsection*{Local and Hierarchical Horizons}

The \DH{} should not be understood only as a single absolute boundary
placed outside all description.
The principle names a structural limit,
and that limit can also appear locally.
Whenever a particular observational window reaches the limit of the
differences it can resolve,
the same structure appears in restricted form.

Such a local \DH{} is not a second fundamental horizon.
It is a local appearance of the same principle:
a generated description reaches the edge of what its own differences
can sustain.
Section~\ref{sec:dynamic_barrier} gives the smallest form
of this principle.
There the apparent rest of the dynamic barrier is shown to be
projection-dependent,
and the barrier becomes a local descriptive horizon rather than an
imposed resistance term.

\subsection*{Counterfactual Description}

What lies beyond the \DH{} cannot be described as a hidden object.
To describe it as an object would already place it inside a generated
domain of difference.
It can only be described counterfactually:

\medskip
\begin{quote}
If difference were absent,
the generated description itself would no longer be available.
\end{quote}
\medskip

This formulation does not make the absence of difference into a region,
substance, or state.
It marks the limit at which the conditions of description fail.

\subsection*{Scope and Provisional Status}

The \DHP{} does not explain existence from outside existence.

\medskip
\begin{quote}
It defines the condition under which explanation becomes possible
from within a generated domain.
\end{quote}
\medskip

It does not introduce new entities.
It does not propose a final unified theory of interactions.
It does not describe what lies beyond the horizon.

The principle is therefore not a final metaphysical closure.
It is the current formulation of a structural constraint.
Its formulation may be updated as observational or mathematical
windows deepen.
However,
as long as observation measures difference from within generated
spacetime,
some limit of describability remains.

\medskip
\begin{quote}
The \DHP{} is not a theory of what exists,\\
but a principle of how existence becomes describable.
\end{quote}
\medskip
